# H有手／无手比较样例

2026-09-20。用户U41明确批准：以精细静态和克制动作作为主线，吸收少量局部姿势替换，同时制作无手抽象供比较。本批两个样例均未被用户选为正式标准。

## 直接评审

- [离线同步对照页](index.html)：普攻、盾击，同屏A/B、播放/暂停、循环、逐帧拖动、1×/2×播放速度、声音开关、关键帧放大、训练场1×人物副图。默认静音。页面使用实际Godot渲染截图，没有生成式重画或CSS摆动代替角色动画。
- 根目录 `Review-Hands.cmd`：启动独立Windows评审包，可另切待机、浅/深/训练场底色与特效开关，反复打靶观察持续甲损。另可从锁定引擎运行。
- 导出包：`builds/hand-style-review/windows/FantasyBrothers-HandComparison.exe`；构建方法 `tools/build_hand_style_review.ps1`。builds不入Git，源码、原始PNG、网页截图序列、声音与来源记录随分支同步。

浏览页每动作16个均匀进度采样帧，按实际动作时长回放；它用于对比，不代表引擎只有16帧。Windows程序按实时帧率绘制。1×/2×按钮指播放速度，训练场右下副图指人物绘制尺度；网页整体缩放后的副图不能当作显示器上的绝对像素测量。

## 两套共用与区别

两套共用原B图集的头脸、剑、底座，新闭合肩袖链甲躯干及三分之四盾面；主手位置、肢体运动和遮挡方式是本次变量。普攻0.72秒、盾击0.62秒，归一化接触点48%，接触保持至56%；静态准备0.35秒、动作结束后观察伤损1秒。参数为本批比较用数值，不冒充用户批准的最终战斗节奏。

| A：自然握持＋局部姿势 | B：无手抽象 |
| --- | --- |
| 主手显示肩、肘、腕和握柄；在预备、出手处替换局部臂姿势，肩胸小幅参与 | 使用完整闭合的链甲短袖轮廓，省略臂手层；武器有独立小幅位移与旋转，胸转更少 |
| 副手位于盾后，盾击时肩袖仍形成连接；不为了露两手破坏防御构图 | 通过武器位置与迎敌盾面暗示持械，不保留黑色空臂洞或截断袖口 |

两者均修正腰底：躯干深入低底座并由前沿遮住接缝。盾移至右向迎敌侧，主手在后侧。三个局部臂姿势来自同一图集整体生成，使用相同像素比例和单独登记的肩／握点，不独立缩放每帧。小尺寸纹理使用与原B素材一致的mipmap导入。

## 实际范围

这是独立训练靶表现样例，尚未接正常战斗；训练靶甲损和反冲属于展示夹具，不修改人物伤势、生命、装备或存档。两个招式共用靶反应、接触效果与声音，便于比较手部方案。当前训练靶为简洁程序形状，不是正式敌人美术。

三段声音是本项目现场合成的挥动、击甲、盾挡示意，供时点与区别判断，未做正式音效听感验收。无第三方录音；普攻30%播放挥动、48%播放击甲，盾击48%播放盾挡。静态切换、拖动与暂停不额外结算一次命中。

本批没有制作反向姿势、其他武器/护甲、完整人物受伤变体或新倒地/死亡。原H无底座终态要求继续有效；不能以训练靶伤损示意冒充整套人物连续伤损完成。

## 来源与生成

内置`image_gen`共2次输出，2张源PNG均保留。第一次生成3个局部臂姿势和1个盾面；第二次只采用闭合肩袖链甲躯干。第二次图集中的其他头、剑、底座等没有采用，避免生成漂移。运行图与原输出逐字节一致，1254×1254 RGBA、alpha范围0–255；没有代码抠图或栅格重画。

[完整提示词](prompts.md)、[来源及哈希](generation-log.json)、[预览文件清单](previews/MANIFEST.tsv)。输入为已有项目B v2图集；用户提供的Battle Brothers图片只用于构图理解，没有作为运行素材复制。新代码和合成声音为本项目制作，源图沿用既有生成资产来源记录；没有引入Spine、其他引擎或外购服务。常规实现、页面和独立检查由Sol专项完成，主AI负责原画、装配、集成和最终复核。

# H · 固定盘面与武器姿态

2026-09-20 / U48，主AI独立完成，无子智能体。[评审页](index.html)默认展示定标顺序，另有前后对照、穿戴/甲损、分层与三武器回放。根目录 `Review-Static-Bust.cmd` 打开实际Windows样板。其他电脑已有旧包时，拉取后运行 `tools/build_static_bust_review.ps1` 重建。

## 用户要求与实现

严格采用“先底座 → 身体和衣甲 → 头部大小/落位 → 最后截取”。本批选定现有H底座原画，宽64逻辑像素，中心(0,0)；完好、受损与每种装备均共用，未按服装重新调底座。

完整衣甲以统一盘面为设计依据，保留长袖与下摆；套入棋子时，身体和各衣甲共用一条侧边/前弧截取边界。肩胸的侧向上部使用原画自然轮廓，前弧覆盖盘面，袖口和下半段落在显示区外。不再露出U47的短袖口或上臂，也不把袖子画成紧收圆垫。

头部沿用H面容与脸伤原画，宽34，落位(3,-28)。下颌贴近衣领，后脑与领口遮挡衔接，不展示明显长颈。尺寸是当前单体型试验规格，并非所有人物的最终固定公式。

按最后追加反馈，人物、头与衣甲整体向右微移2逻辑像素，底座固定。截取下缘从底座原画盘面测定同一条前半圆弧，保留右侧微露的边缘及完整前侧金属圈；裁取窗口不随人物平移。检查页金线与最终截取使用同一边界。

## 原画与构图资料

内置 `image_gen` 两次成功生成完整衣甲和对应甲损，原图在 `sources/`，原样复制为 `full-garments.png` / `full-damaged.png`。头、底座、武器和绘制命中效果沿用此前原画。共5运行图集、15部件。

基础身体采用素色内衣外观，没有声称生成了新裸胸/完整人体解剖。原画领口保留绘制的内衬阴影，头部靠低落与遮挡贴合；当前只验证这一套配套内衬/绗缝/链甲，不代表任意领型或衬色已全部通用。

PNG没有被程序重绘或涂补；Godot按相同盘面边界显示源纹理的相应区域，不改变其纵横比。完整原画可在“盘面与截取”查看。金线是评审辅助线，最终棋子上不绘制。

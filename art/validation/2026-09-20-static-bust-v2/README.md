# H · 侧身与比例修订

2026-09-20 / U47。主AI独立完成，未启动子智能体。用户认可上一版总体观感和动作，本轮修正头身比例、肩胸朝向、短上臂、底座与武器比例。

[打开前后对照与动作回放](index.html)。根目录 `Review-Static-Bust.cmd` 运行 Windows 评审器；其他电脑更新源码但仍有旧导出包时，先运行 `tools/build_static_bust_review.ps1` 重建。

## 改动

- 独立头部宽度51→37，约缩小27%；衣甲宽度约缩小8–9%，头肩宽比由约0.65调整至0.51。保留同一个H人物和脸伤原画。
- 身体、亚麻、绗缝和链甲重新绘为同向右侧构图。近侧肩和短上臂更明显，远侧肩退后；衣袖自然向下，没有在腋下收成圆垫。
- 底座宽度75→56，向胸部承重点微移；短上臂允许自然伸出底座两侧。
- 剑放大约18%、枪20%、弓25%，盾约7%。枪和弓的待机位置重新校准，弓在整个蓄势过程中避开脸。三类武器时长、出手与停顿节奏不变。
- 实机和网页均有同尺寸前后对照：统一镜头倍率，不把两版分别缩放至相同占格大小。

这些是当前单一体型样板的逻辑尺寸，不是所有人物的固定公式。网页图片与动作均来自实际Godot导出包渲染。

## 原画、来源与成本记录

内置 `image_gen` 共6次调用：5次获得图像，1次裸身体拆件被输出审核拦截。基础身体改穿素色贴身内衣，保留颈根和短上臂；不标作裸身资产。全部提示见 [prompts.md](prompts.md)。

选用 `sources/04-layers-spaced.png` 与 `sources/05-damage-spaced.png`，原样复制为运行图集 `side-layers.png`、`side-damage.png`；身体/亚麻只取完好图集。第一版图集隔距不足，重新生成留白版本，没有裁掉肩尖或用程序涂补接缝。`01-master.png` 仅作方向参考，其脸伤未被当作健康面容使用；02、03为退回的紧排图集。

沿用U46的独立头/伤脸、低底座、剑枪弓盾箭及绘制命中效果。当前合成使用5张图集、15个部件。旧目录和 `catalog-v1.json` 保留原版比例。索引工具仅读alpha/尺寸并写配置，PNG像素不被重绘、拉伸或修补。

用户提供的Battle Brothers截图和[艺术设定集](../../../references/battle-brothers/README.md)仅作为结构与比例参考，运行素材不是直接裁取游戏资产。来源/哈希见 [manifest.json](manifest.json)，部件矩形和尺寸见 [metadata.json](metadata.json)。

## 范围

一个体型、两层甲、三类武器的修订样板，未替换正常战役全部人物。链甲破口的绗缝衬色是配套原画，尚不代表任意内衬材质互换。更多人物、朝向、倒地/死亡与正式音效不在本轮；倒下可能重伤幸存的规则方向不变。技术验证不替代用户美术评审。详见 [QA.md](QA.md)。

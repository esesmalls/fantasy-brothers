# H标准：三套动作样板评审

双击项目根目录 `Review-Motion.cmd`，或运行包内 `Review.cmd`。

**A 简练利落、B 重量明确、C 细腻舒展**保持同一人物和剑盾，比较材质密度、预备幅度、接触停顿和收势节奏。当前是v2候选评审版，已修订用户指出的四处连接问题；不是全游戏正式美术替换。首轮退回原因保留在 `FEEDBACK.md`。

操作顺序：

1. 选择A/B/C与轻型衬甲或重型链甲。
2. 左侧选择待机、移动、挥砍、盾击、防御、受击或倒下，暂停后拖时间检查握点和接缝。
3. 右侧选择真实动作再点击目标格。普通攻击/盾击点击相邻敌人，移动点击合法空格，防御点击自身；行动点不足可重置试打。
4. 比较1×、2×和跳过；再回主菜单进入原战役，检查同一人物在营地和完整战场中的实际尺寸。

独立试打只使用内存状态，不读取或覆盖个人战役。回主菜单后原游戏保存规则仍照常生效。

本批只覆盖一名固定身份的人类、营团剑盾、现有轻型衬甲/重型链甲。其他武器和人物沿用原外观。死亡沿用当前HP归零规则；没有实现战后重伤幸存，也没有新增斩首判定。三套共用两甲无底座倒伏资源。

## 可复用交付

- `sources/`：无损生成原件（含退回稿）；当前运行使用三个 `*-atlas-v2.png` 和共用终态；`prompts.md`与`generation-log.json`：来源、提示词、哈希。
- `game/assets/art/motion/catalog.json`：部件区域、共同尺寸、握点和三套动作参数。
- `docs/20-motion-template-production.md`：新增兼容资产的生产和检查方法。
- `tools/validate_motion_assets.py`：缺件、区域、透明度与尺寸校验。
- `tools/build_motion_review.ps1`：检查与Windows评审包导出。
- `builds/motion-review/`：本机实际引擎截图、运行报告与动态预览；可重新生成，不入Git。

使用内置image_gen完成候选资产。没有购买外部服务或切换到图片API。批量生产仍需要逐件锚点与接缝检查，不能直接把生成图按等分格裁入游戏。源图和运行图集分开留存，角色动作不逐帧读取文件。

已知边界：默认三分之四朝右是本批主要验收朝向；其他朝向没有新增专用手势。全套四档甲损、永久伤残、多体型、弓枪和双手武器未制作。声音未作为本批交付项。当前样板不能据此宣布全库已可批量放行，应先由用户选择动作/细节偏好。

三套同步播放的实机动图位于本机 `builds/motion-review/slash-comparison.gif` 与 `shield_bash-comparison.gif`；游戏内可单独慢放、暂停拖动。实际测试结果与观察见 `QA.md`。审美评价留给用户，不把技术检查通过写成用户批准。

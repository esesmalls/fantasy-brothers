## 来源、成本与可维护性

内置image_gen共6次成功输出，选用3张。04/06各1次，07共4次。07前两稿从E07派生，虽有透明alpha但独立QA指出脸型、扣带和剑形残留；第3次为多余透明提取。最终第4次改从H06派生，保留H原脸与配装。未使用CLI/API、外购服务或额外模型采购；工具没有暴露可核算的模型版本和费用，不能推算账单。详见[prompts.md](prompts.md)、[generation-log.json](generation-log.json)和[manifest.json](manifest.json)。最终PNG为工具原始输出，仅复制入项目，没有代码抠图或重绘。

直接输入是项目第二轮H04/H06、E04/E07、G04及本轮派生图；H的前轮造型研究参考用户指定设定集。第三方设定集没有成为运行素材。最终源PNG、提示/来源和SHA-256进入版本管理，另一台机器无需重新生成来取得同一图。生成式编辑不保证复跑逐像素一致，复现以保留的原始PNG与哈希为准。

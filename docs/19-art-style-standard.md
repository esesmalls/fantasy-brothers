# H主导人物美术标准

更新：2026-09-20。适用于人物、装备、动作、倒地与死亡资源的下一轮样板和后续正式化。详细生产范围、工程接口与发布条件仍见[18美术升级计划](18-art-production-plan.md)。

## 1. 已确认方向与验收边界

用户对第二轮的评分为E 4/5、F 1/5、G 4/5、H 4/5，并明确选定 **H作为总体风格**。后续不再并列扩展四套风格，也不继续使用F方向。E和G只提供少量写实结构与轻度油画笔触，不能改变H的紧凑半身轮廓、清楚外边线、角色占比和腰部贴合底座的关系。

这次确认锁定的是风格母版与制作规则，不等于第二轮H现有图片已经成为正式游戏资源。第二轮图片仍是构图参考；头身与装备的真实像素装配、透明边缘、统一锚点、正常游戏缩放、动作连续性、声音/特效配合和Godot导入均未验收。

本轮已制作[H标准三状态修订样板](../art/validation/2026-09-20-h-standard/README.md)及[对照页](../art/validation/2026-09-20-h-standard/index.html)：04武装、06去底座倒地、07去底座死亡。三张均有真实透明alpha，具体视觉与像素复核见目录内QA；新图尚未获用户逐张验收，也未完成游戏装配。

## 2. 视觉主次

玩家首先应读到人物身份、朝向、武器与当前状态，其次才看到材质细节。统一优先级如下：

1. H的紧凑半身剪影、大头比例、棕黑外轮廓与明确脸部骨相。
2. H的角色有效占比和短腰收束；站立人物与低矮椭圆底座形成一个整体。
3. 完整双手、武器出手方向和不受遮挡的面部表情。
4. 装备类别、甲损与伤势的可读差异。
5. E/G式的轻度画笔肌理、旧化和材质细节。

E/G影响必须克制。皮肤、布、皮、链甲和金属可增加不规则笔触、磨损与局部色温变化，但不能把轮廓打散、把小尺寸变成纹理噪声，或使角色转向E/G现有的较长腰身和较写实全身比例。

## 3. 站立人物与底座

### 3.1 比例与接触

- 以H的角色大小、头身关系和腰部贴底座方式作为母版起点；其他人物、护甲和姿态在同一有效占比内校准，不能按各自可见边缘单独缩放。
- 站立人物的衣摆、腰带或下躯干必须自然收进底座顶面，形成可读的遮挡和接触关系。不得出现腰部悬空、底座切进腹部、衣甲停在底座上方，或用横向硬切口假装贴合。
- 底座保持低矮，不抢脸和武器。底座顶面、金属外圈与人物下缘的透视必须一致。
- 人物换甲、受伤或改变表情时，底座位置和角色整体尺度不变；长武器通过画布留白和轨迹边界处理，不能缩小整个人物来防裁切。

### 3.2 手与武器

- 站立01–05必须保留两只完整、可辨的手。双手自然高于腰线和底座上缘，不能垂在底座两侧或被衣袖、甲片、武器吞掉。
- 02/03换甲状态也要显示完整双手，并沿用04的肩、肘、腕和握点体系。不能把“未持械”理解成隐藏手部。
- 04/05先确定面向、预备姿势和出手通道。武器不得倚胸、倚肩、穿脸或与视线方向冲突；主手、副手和武器转轴在同一母版登记。
- 当前样板优先验证一个朝向的一套完整动作。未来反向攻击不能简单镜像整张角色，避免伤疤、惯用手和装备装饰换边。

### 3.3 第二轮问题如何处理

| 方向 | 可保留 | 不可继承 |
| --- | --- | --- |
| H | 紧凑剪影、角色大小、短腰贴底座、04双手剑预备姿态、06倒伏构图 | 06背后的底座；未经校准的背景、边缘、部件比例和锚点 |
| E | 面部和旧甲的写实质感、05伤势层次、E07连贯死亡处理 | 02–05腰部与底座脱节、02/03缺手、较长躯干与过密细节 |
| G | 少量蛋彩/油画笔触、布与皮鳞甲的色块区分 | 腰底瑕疵、02/03手位过低、05甲损不明显、普通化死亡效果 |
| F | 无 | 不继续作为风格或生产方向 |

## 4. 装备、伤势与分层

所有站立状态共用固定画布、地面原点、头颈、左右肩、左右肘腕、左右握点、武器转轴、腰线和底座接触线。独立头、身体、内衬、主甲、手臂/手、武器、前景遮挡与底座保留稳定ID及层序；允许局部姿态适配，但不得靠临时缩放或平移掩盖不合身。

装备变化必须保留同一个人的脸、骨相、发须、体型和姿势基底。颈口、肩线、袖口、手腕和腰底是逐件检查点。02、03、04重组后要与批准的整体效果对照，不能把独立装备图直接叠上便称完成。

甲损必须改变材料本身，并在正常战场尺寸仍可辨：布甲出现撕口、松线或填料；皮甲出现磨边、裂口和扣带问题；链甲出现断环、塌陷或内衬暴露。损伤位置和程度读取规则给出的护甲状态，不由动画或图片自行决定。不得只加一条通用红痕，也不得像G05那样在高细节中几乎读不出甲损。

脸部伤势、甲损、武器血迹和永久疤痕分层记录。修甲不能清除人物伤势；改变表情不能换脸；没有规则来源时不生成失明、断肢或其他永久后果。

## 5. 倒地与死亡

### 5.1 倒地待清点

- 以H06的俯伏重量、头部落地和双臂外移作为构图参考，保持完整身体、原人物身份与原装备。
- 倒地姿态不带底座。底座属于站立棋子定位语言，不能跟随身体翻到背后、压在身下或留在画面角落。
- 姿态必须明确是失去战斗能力：四肢受重力支撑、身体与地面有接触和压褶；不得枕臂、安睡、撑肘欲起或继续战斗。
- 倒地尚未等于死亡，不提前使用断头、致命伤口、骷髅或只属于确认死亡的血迹。状态文字与图标仍读取规则结果。

### 5.2 确认死亡

- 死亡姿态同样不带底座，并延续E07获认可的整体处理：尸体、分离头部、双臂、衣甲、伤口与落地关系构成一个连贯终态。
- 禁止把正常站立身体、独立头、空甲和武器作为普通模块散放来冒充尸体。死亡需要专用倒伏身体、接触阴影、伤口和装备受压适配；即使复用部件，也必须经过同一构图的人工整合。
- E07是伤口实体感与死亡连贯性的参考，不代表所有死亡都必须斩首，也不自动新增斩首规则。具体终态必须由规则提供的死亡类型或已保存表现ID选择。
- 倒地转死亡时保持同一人物、同一装备和同一耐久状态；血迹、烧焦或元素残留只在来源事件支持时出现。

## 6. 一套完整动作的反馈标准

扩充角色和武器数量前，先用一个H标准角色完成并验证一套攻击。动作必须包含：

| 阶段 | 玩家应读到的内容 | 表现要求 |
| --- | --- | --- |
| 预备 | 谁行动、面向哪里、使用什么武器、目标是谁 | 重心与武器蓄势清楚；目标与合法格提示保持可见 |
| 出手 | 动作方向、速度与武器重量 | 手、武器和身体沿同一出手通道；锚点不漂移，装备不穿插 |
| 命中/落空 | 是否命中、格挡、破甲或落空 | 接触点、短停顿、材质对应特效与声音清楚；不靠过量闪光遮住结果 |
| 恢复 | 动作结束且可以继续操作 | 回到稳定姿态或规则指定终态；不留下错层、残影或输入锁 |

声音、刃光、血滴、火星、尘土和镜头反馈与动作事件同步，但只表现已经由规则确定的结果。动画回调不得决定命中、伤害、护甲扣除、行动点或资源消费。

同一夹具至少检查1×、加速和跳过。加速后仍要读到行动者、方向、接触结果和最终状态；跳过可以省略中间帧，但必须立即显示正确终态、数值变化和必要的短声音/提示，不能因跳过漏掉死亡、甲损或规则日志。

## 7. 透明边、缩放与导出

本标准的直接视觉依据是[第二轮E–H交付](../art/validation/2026-09-20-refined-directions/README.md)中的E、G、H图片及其manifest、prompts和QA记录。该批素材全部由内置`image_gen`生成或参考编辑；H另参考用户指定设定集第6页的模块与半身比例。设定集是第三方研究参考，不是本项目可发布素材。专项文档工作复核了原图片；主代理同期使用内置image_gen制作三状态修订，来源和6次生成记录见新样板目录。未调用CLI/API，未改游戏导出。

- 源资源使用统一RGBA工作画布和固定锚点；保留可编辑分层源，或无损部件PNG加完整组合/定位清单。具体工作尺寸沿用18计划，直到样板校准给出新的实测结论。
- 每件导出检查黑、白和实际战场三种底色：无白边、黑晕、棕色光圈、彩边、矩形背景、孔洞和半透明脏像素。
- 角色整体按相同标尺导出，不能逐张裁到内容边缘后再各自放满。记录有效包围盒、地面原点、腰线、底座接触线、头颈和握点。
- 在近景检查脸、材质和接缝，在实际战场大小检查轮廓、双手、武器方向、伤势/甲损和底座接触。链甲、头发和细笔触缩小时不得闪烁或糊成噪声。
- 交付记录稳定ID、版本、来源、生成工具与日期、可得的模型信息、提示词/参考关系、人工修整、导出参数和内容hash。参考设定集只作研究来源，不进入游戏导出。

## 9. 成本与返工控制

H轮廓是必须保持的低层结构，E/G质感是可削减的高层细节。若缩小后纹理变脏、链甲闪烁或修整时间超出样板估算，先减少笔触密度和局部细节，不改变角色比例、双手、武器方向和腰底接触。

死亡资源允许比普通换甲投入更多专用绘制，因为E07式的连贯终态不能由通用模块自然得到；仍先只做一个确认死亡样板并记录尝试数、通过率、修整时间、文件体积和返工原因。无法取得实际账单时只记录工具与用量，不虚构现金成本。

新增角色、装备方向和大量动作必须等待一个角色的一套完整动作及04/06/07状态通过。样板未通过时修母版和接口，不用批量生成掩盖结构问题。

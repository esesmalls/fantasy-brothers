# 装配台 v2 与人物重制入口

2026-09-21 · U51 · 用户校准 + 独立身体及附着部件。主 AI 独立完成。

## 当前可以直接使用的工具

- 位移从 ±20 扩至 **±128 逻辑像素**，等比缩放从70%–130%扩至 **25%–300%**。
- 部件可绕现有锚点旋转 **±180°**；右侧输入角度或 **Alt＋左键拖动**。完好／破损甲、正常／受伤头成对调整。
- 普通拖动平移；方向键微调0.25，Shift加速至1。附着部件的拖动会换算到父部件坐标，旋转头部后仍跟随鼠标移动方向。
- 撤销／重做显示可用步数；Ctrl Z、Ctrl Y、Ctrl Shift Z。一次完整拖动或旋转为一步，部件启用与整头／拆件切换也入历史，最多100步。
- 中键拖动平移视图；“定位选中部件”找回移远的部件，“视图归位”恢复镜头。“查看选中部件原图”以半透明显示裁取外的完整源图，只用于诊断。
- **身体 · 裸身**与**基础内衣**明确分开。选择身体会切到裸身检查，也可再切上方衣甲检查其包裹关系。
- “启用部件”随草案保存；“临时隐藏”仍只用于观察，不改角色配置。切到 **H 拆件试样**才能独立开关发须；原整头中的发须仍是原画的一部分。
- 当前新部件有：无发净面头、头发、胡须、脸部伤痕、头部绷带、皮肤血迹各一件；身体在用户追加朝向反馈后进行了局部侧向重绘。它们是工具验证样件，尚未作为全库风格／结构定稿。

穿戴层序继续锁定；人物整体仅平移。底座锚点与盘面裁取现可在工具里调整，默认等于现行硬编码范围，不改则已有资产显示不变。工具不是骨骼编辑器，仍为无手静态半身；武器路径可编写，见[28](28-paperdoll-authoring.md)。

## 部件与遮挡规则

| 部件 | 依附对象 | 可见关系 |
| --- | --- | --- |
| 裸身 | 人物整体 | 固定盘面裁取；位于衣物下 |
| 净面头 | 头部组 | 与旧头共享装配锚点；独立试样原画 |
| 头发、胡须、绷带 | 头部组 | 继承头部平移、缩放和旋转，并可局部调整 |
| 脸伤 | 头部组 | 受当前头的透明轮廓限制；绷带可以遮住伤口 |
| 皮肤血迹 | 裸身 | 受裸身轮廓与盘面限制，穿衣后被实际衣料遮住 |
| 衣甲 | 人物整体 | 继续按已有透明领口／破口显示下层；本轮没有把皮肤血迹画到衣服外面 |

顺序：底座 → 身体／皮肤血迹 → 内衣 → 亚麻 → 绗缝 → 链甲 → 头／伤痕 → 胡须 → 头发 → 绷带 → 武器。未来头盔、后发片、甲面血迹等需要各自的附着对象和前后关系，不能把同一张贴花无条件覆盖所有部件。

程序仅执行坐标变换、透明轮廓遮挡与既有盘面裁取。没有用噪点、色块或算法画伤痕、发丝与血迹；新图集由内置 imagegen 生成，像素保留原样。

## 人与 agent 共用的配置

schema2 增加 `modules_sha256`、`appearance`，每个 `edits` 支持角度 `angle`（度）。schema1继续读取；原 U50 `catalog.json` 不改，新部件单独注册在 `modules.json`。模块摘要不同拒绝盲载，迁移需重新核对定位。两类摘要都不代替 PNG 来源与内容版本记录。

```json
{
  "schema": 2,
  "kind": "fantasy-brothers-paperdoll",
  "baseline_sha256": "从当前示例复制",
  "modules_sha256": "从当前示例复制",
  "appearance": {"head":"modular","skin":true,"hair":true,"beard":true,"scar":true,"bandage":false,"blood":false},
  "edits": {"head":{"offset":[0,0],"scale":1,"angle":5},"scar":{"offset":[1,0],"scale":0.9,"angle":-5}}
}
```

新增组 `skin / hair / beard / scar / bandage / blood`；旧 `body` 仍指基础内衣，避免破坏用户旧配置。局部变换后应用父部件变换，最后平移人物整体。发须／脸伤／绷带的局部位移以头部未缩放坐标计；血迹以身体坐标计。导出候选带附着信息与启用状态；不带临时隐藏、甲损预览、镜头或战役状态。

现有 `paperdoll_cli.gd` 自动使用新校验与渲染配置，调用方式见25文档。注册新样件目前由 agent 在 `modules.json` 添加源图矩形、锚点、尺寸和依附关系；**GUI 现可调底座锚点、盘面裁取和层高，仍不支持随意拖入 PNG**。层高默认保持现行绘制顺序，见[28](28-paperdoll-authoring.md)。

## 身体偏大反馈与美术边界

第一次把旧裸身接入时，宽63且肩线过高，肩部露到现有衣服外面。用户在制作过程中明确指出“身体明显偏大”。先缩至宽52并压低肩线；用户追加“身体朝向有问题，可以再倾斜一点”后，又局部重绘肩胸。用户随后反馈“侧过了”并提供参考、要求少留脖子，最终回调为轻微右侧向：双侧胸肩可见，远肩仅略收窄，移除明显颈柱，让头直接落在肩领处。继续以宽52、固定盘面和衣物包裹为约束，原画等比显示，头、衣物和底座保留原校准。实际渲染确认两侧仍不露裸肩。先前截图在本机 `builds/u51-visual`、`builds/u51-visual-v2`、`builds/u51-visual-v3` 留作过程记录，交付截图来自最终 `builds/u51-visual-v4`。

首次单独身体补图被图像工具输出审查拒绝，没有可用输出。后续用户追加朝向反馈后，对现有图集的身体区域局部编辑成功；只采用新身体，不替换同图集中的脸、伤脸、底座。当前仍只验证一个体型／头型，侧向修订待用户目视确认，不推定所有发型、头盔或所有脸伤已适配。

## 下一步如何启动人物重制

可以用这版工具启动正式重制的第一套小样。按顺序做：

1. **锁一套结构母版**：固定底座与弧线；复评本次缩小、侧向修订后的裸身；净面头与肩胸方向相同、无明显长颈。在1×与2×下审查，先解决结构再铺材质。
2. **用同一母版制作完整拆件人物**：净面、前后发、胡须、表情、局部伤痕、绷带；同一头型与衣物的交叠、头盔遮发逐项验证。每件只有本层内容，不带另一件材质或背景补丁。
3. **重制一组真实嵌套衣甲与武器**：内衣→亚麻→绗缝→链甲，保持领口开口、完整／破损配套；甲面血迹另建依附于具体甲层的部件，不借用皮肤血迹。剑、枪、弓待机和出手不改变已确认静态路线。
4. **通过后再扩身份与装备数量**：先用第二个不同面容／发须检验复用，再扩库；倒伏、幸存重伤与明确死亡继续分开设计。工具通过不等于人物美术自动验收。

当前不启动Spine、不引入新体型骨骼或新付费工具、不改变战役规则／存档。

# 装配台：盘面、多选与武器动作编写

2026-09-21 · 美术设计阶段小增量。主 AI 独立完成。

现行纸娃娃仍是资产设计工具。本轮只解开三件已挡住制作的限制：硬编码盘面、单层编辑、武器路径写死。默认显示必须等于改前的硬编码范围。

## 给制作者的变化

1. **盘面裁取与底座锚点可调。** 左侧选「盘面裁取」可改中心、横向／纵向半径和顶边；选「底座 · 锚点」只移动底座位置。不改则继续使用现行 `bust_crop`：中心约 `(-0.049767,-17.219285)`、半径约 `(28.765163,7.166407)`、顶边 `-120`，底座仍在 `(0,0)`。超出旧窗口的衣甲或人物，把半径或顶边加大即可看见，不会改原画像素。
2. **多选统一变换。** Ctrl 点选多个部件后，右侧位移、等比大小和旋转会一起写入选中项。人物整体和底座仍只平移。一次拖动或一次数值修改算一步撤销。
3. **武器动作可编写。** 剑／矛／弓各有一条带稳定编号的路径，例如 `sword`、`sword.contact`。可改时长、出手／离弦、接触／结果点，以及各关键帧的时间与武器位移／角度。播放与拖动进度条预览同一取样结果。恢复默认动作即回到现行硬编码路径。

规则状态与表现分开：预览和结算共用 `static_bust_motion.sample`；命中、伤害和资源仍由规则决定，动作文件不能改战役结果。

## 配置

未改盘面或动作时仍保存 schema2，旧草案可原样打开。一旦写入裁取或武器路径，保存为 schema3：

```json
{
  "schema": 3,
  "kind": "fantasy-brothers-paperdoll",
  "baseline_sha256": "从当前示例复制",
  "modules_sha256": "从当前示例复制",
  "appearance": {"head":"legacy","skin":true,"hair":true,"beard":true,"scar":false,"bandage":false,"blood":false},
  "edits": {"base":{"offset":[0,0],"scale":1,"angle":0}},
  "crop": {"center":[-0.049767,-17.219285],"radius":[36,10],"top":-90},
  "actions": {
    "sword": {
      "id": "sword",
      "weapon": "sword",
      "duration": 0.86,
      "release": 0.25,
      "contact": 0.42,
      "keyframes": [
        {"id":"sword.rest","t":0,"x":8,"y":-12,"angle":0.62},
        {"id":"sword.contact","t":0.42,"x":22,"y":-31,"angle":1.55}
      ]
    }
  }
}
```

`actions` 只保存改过的武器。关键帧角度以弧度存储，界面用角度编辑。导出候选会带上改过的 `bust_crop` 与 `actions`，便于下游对照；它仍不是战役规则。

## 边界

- 不是骨骼或全身动画编辑器；身体保持静态半身。
- 没有新的战斗招式、音效、倒伏或六向专用姿势。
- 默认路径的观感与 U48／U51 相同；编写结果仍待用户目视。
- 游戏／存档仍为 0.1.5.1。原 catalog 与 PNG 未改。

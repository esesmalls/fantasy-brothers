# 装配台：盘面、多选与武器动作编写

2026-09-21 · 美术设计阶段小增量。主 AI 独立完成。

现行纸娃娃仍是资产设计工具。本轮只解开三件已挡住制作的限制：硬编码盘面、单层编辑、武器路径写死。默认显示必须等于改前的硬编码范围。

## 给制作者的变化

1. **盘面裁取与底座锚点可调。** 左侧选「盘面裁取」可改中心、横向／纵向半径和顶边；选「底座 · 锚点」只移动底座位置。不改则继续使用现行 `bust_crop`：中心约 `(-0.049767,-17.219285)`、半径约 `(28.765163,7.166407)`、顶边 `-120`，底座仍在 `(0,0)`。超出旧窗口的衣甲或人物，把半径或顶边加大即可看见，不会改原画像素。
2. **多选按原值增减。** 左侧勾选多个部件后，改右侧某一个数值，会给每个已选部件的该参数加上相同变化量，其它参数保持各自原值。点「对齐参数」才把最后选中项的左右、上下、大小、旋转和层高写成相同值。人物整体和底座仍只平移。一次拖动、一次数值修改或一次对齐算一步撤销。若子部件和它的父组件，或和人物整体一起被选中，平移只记在上层：发型、胡须、伤痕、绷带跟着头部，血迹跟着裸身，头身衣甲跟着人物整体。子部件自己的位移数字不变，画面上只走一次。单独选中子部件时，仍可改它自己的位移。
3. **空白处框选。** 在主视图没有部件的地方拖出矩形，选中当前看得见、并与矩形相交的部件；按住 Shift 再框是追加，不会清掉已经选中的。从已选部件上拖动仍是平移。人物整体处于选中时，从头身衣甲上拖动移动的是整体。点在未选中的部件上会改选该项再移动。Alt 拖动仍是旋转。
4. **武器动作可编写。** 剑／矛／弓各有一条带稳定编号的路径，例如 `sword`、`sword.contact`。可改时长、出手／离弦、接触／结果点，以及各关键帧的时间与武器位移／角度。播放与拖动进度条预览同一取样结果。恢复默认动作即回到现行硬编码路径。

规则状态与表现分开：预览和结算共用 `static_bust_motion.sample`；命中、伤害和资源仍由规则决定，动作文件不能改战役结果。

## 配置

未改盘面或动作时仍保存 schema2，旧草案可原样打开。一旦写入裁取或武器路径，保存为 schema3：

```json
{
  "schema": 3,
  "kind": "fantasy-brothers-paperdoll",
  "baseline_sha256": "从当前示例复制",
  "modules_sha256": "从当前示例复制",
  "appearance": {"head":"legacy","skin":true,"hair":true,"beard":true,"scar":false,"bandage":false,"blood":false},
  "edits": {"base":{"offset":[0,0],"scale":1,"angle":0}},
  "crop": {"center":[-0.049767,-17.219285],"radius":[36,10],"top":-90},
  "actions": {
    "sword": {
      "id": "sword",
      "weapon": "sword",
      "duration": 0.86,
      "release": 0.25,
      "contact": 0.42,
      "keyframes": [
        {"id":"sword.rest","t":0,"x":8,"y":-12,"angle":0.62},
        {"id":"sword.contact","t":0.42,"x":22,"y":-31,"angle":1.55}
      ]
    }
  }
}
```

`actions` 只保存改过的武器。关键帧角度以弧度存储，界面用角度编辑。导出候选会带上改过的 `bust_crop` 与 `actions`，便于下游对照；它仍不是战役规则。

## 棋盘格、层高与分类

主视图默认画出与战场相同的尖顶六边形：半径 34，第一顶点在 30°，人物原点就是当前棋格中心，周围六格淡显。右侧「棋盘格」可单独关掉；1× 缩略图和「战场尺寸检查」使用同一套几何。

层高是绘制先后，数值越大越靠前。默认间隔 10，顺序仍是底座、身体／血迹、内衣、亚麻、绗缝、链甲、头、伤痕、胡须、发、绷带、盾、武器。人物整体和盘面裁取没有层高。改层高不改位移、大小或旋转；与默认相同则不写入文件。一旦改过，草案保存为 schema 4，并增加 `layers`，例如 `{"head":200}`。schema 1–3 照旧打开。没有 `layer_ranks` 的目录仍按原来的顺序绘制，正常战役不受影响。

左侧用下拉菜单切换分组，分类可以折叠，以后加资产时在分组表里加一项即可：

- 组件类型：参照、身体、护甲、头盔与头面、武器（对照战场兄弟的物品栏；盾归在武器）。
- 层位置：后层、身体层、护甲层、头面层、前景、操作项。
- 名称：原来的平铺列表。

不同分类里的部件可以一起勾选，再点一次只取消该项。点分类名称会选中或取消该组，不会清掉其他分类里已经勾上的部件。

## 运行时视觉映射

当前棋盘样板使用 [runtime-profile.json](../game/assets/art/static-bust/runtime-profile.json)。头、伤头和底座取自仍在目录中的 `body-mild-proof.png`；拆件头面取自 `modular-proof.png`。它由 `my_test-v2.json` 的最新组件调整提升为运行时视觉 profile：每个单位所在棋格的中心点是该单位的绘制原点，所有部件的 `position`、`size`、`pivot` 与组件变换都相对于这个点组装；没有特殊 profile 覆盖时，同一组件在不同人物配置中保持相同参数。`modular_actor.gd` 对 `crew_1` 或显式 `visual_profile` 单位读取该 profile，其他单位继续走原模块化或程序绘制回退。

目前 profile 是显式提升的运行时样板，不会因保存任意外部草案而自动覆盖正式资源；确认新的装配结果后，应更新 profile 并重新运行模块与静态半身回归。

## 边界

- 不是骨骼或全身动画编辑器；身体保持静态半身。
- 没有新的战斗招式、音效、倒伏或六向专用姿势。
- 默认路径的观感与 U48／U51 相同；编写结果仍待用户目视。
- 游戏／存档仍为 0.1.5.1。原 catalog 与 PNG 未改。层序默认仍是锁定顺序，只有用户改过的层高才写入草案。

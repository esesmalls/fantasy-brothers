# A 标准人物、套层与动作生产

## 已确认范围

U42：采用自然手部 A，少量局部关键姿势替换；身体朝面向方向倾斜，攻击武器保持可见，命中后减速、停顿和回收。主 AI 亲自生产，不安排子代理，完成后上传云端。

U43：本批覆盖当前全部人物类别、10 个武器定义、4 个护甲定义和相应动作。U44：装备套层必须实际检查。此范围不自动增加装备槽、战斗数值、伤亡规则、世界或 UI 美术。

交付入口：[动态回放与套层](../art/production/2026-09-20-a-standard/index.html)、根目录 `Review-A-Standard.cmd`。本批是右向资产库及独立运行评审器；正常战役仍使用原表现，不把右向库声称为六向战场已接入。

## 套层的实际结构

1. 低底座固定，身体腰线埋入底座，前沿最后覆盖接缝。
2. 亚麻内衣是独立透明资源。
3. 皮甲、钉甲、链甲加防护衬衣；轻型衬甲本身就是外面的衬甲，不能再在破洞下面画一件相同完好衬甲。
4. 四甲的外壳各自有完好、受损、重损、耗尽四档。外壳真实透明破洞露出下层材质。
5. 领口前缘压住颈点，近肩甲压住袖根，腰带覆于胸甲之上。三者使用原图的独立 UV 区域绘制，没有在离线加工中涂抹原始 PNG。
6. 头、手臂、盾、武器分别定位。攻击中的武器和握持手最后绘制，训练靶也不能遮掉武器。双手长枪以两处实际握点校准，弓弦连接弓梢与拉弦手。

当前两规则槽“武器／护甲”的组合已覆盖。内衣、防护衬衣、领肩腰带是视觉层，不新增购买、属性或存档槽。头盔、披风、独立副手、可换袖型没有生产和接入，不能宣称任意套装都适配。衬衣图仍包含其自身腰带和肩部结构，当前外甲可以覆盖；将来新增极端轮廓时须重新裁定部件，不能直接任意相叠。

| 倒伏 | 四甲 × 侧倒／仰倒 2 姿态；完好与受损资源，重损新增裂口与血渍；头、武器、盾单独装配，无底座 |

身份读取 `visual_identity`，缺省由稳定单位 ID 的冻结映射得到；换装备不换脸、不消耗规则随机数。映射目前只在表现层使用，未添加新的存档字段。发型胡须仍画在各脸中，未做成独立可组合库。新增单位可复用 12 身份，不代表有 12 个固定剧情角色。

四档甲损按当前护甲／最大护甲读取：0、低于30%、低于67%、其余。倒伏目前是较粗的完好／受损分档，皮甲、钉甲、链甲另保留中间磨损版本；并非站立每一个裂口都能逐像素延续到卧姿。倒地与死亡使用不同姿态，不新增生死判定；更细的致死部位和完整连续摔倒序列仍未制作。

## 动作节奏

表现时钟使用秒，预备 → 出手 → 碰撞减速 → 固定停顿 → 回弹 → 收回。固定停顿期间握点、武器角、身体倾角及靶体反应保持一致。落空不黏住，格挡回弹较强。弓先松弦、箭飞行、目标后受击；远程停顿作用于目标，拉弦臂按松弦时点收回。

## 交接

原 PNG 保留，不做离线抠图或重采样；索引脚本只读取 alpha 与坐标，Godot 在运行时读取区域和锚点。全部来源、工具提示与哈希见本批目录。资产构建必须包含 `assets/art/a-standard/*.json`，否则导出后不能装配。

正常战场接入前仍需六向专用姿势与遮挡验证，并决定脸部映射的持久化迁移；不能简单镜像整个人物来翻转疤痕和惯用手。本批未通过新增规则伪装美术覆盖，也不自动推进后勤、契约等四步功能。

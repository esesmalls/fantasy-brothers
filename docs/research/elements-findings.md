# 元素反应与场景互动调研

核对日期：2026-09-17。一手资料与原创实验建议，未进行游戏实现。本文记录研究选项；采用方案以 [系统扩展设计](../04-systems-expansion.md) 为准。“轮”指全体单位的行动周期，“回合”指某单位的行动时段。

## 1. 核实的外部事实

Divinity: Original Sin 2 的发行版帮助手册说明雨造水并灭火、雷使水带电、火引爆毒面；门可开启或破坏，物件可以搬动，移动有路径与行动点预览。这里依据 Xbox 托管游戏帮助，不是玩家攻略。[官方手册](https://dlassets-ssl.xboxlive.com/public/content/6778dff3-8d6c-4615-a8a3-1f1770057d09/GameManual/9e540603-b9bb-44a0-83cd-bb98f1d40b32/nb-NO/index.html)

Larian 自托管的引擎文档区分 Ground 与 Cloud 层，并限制不成立的组合；IsSurfaceBlocker 可阻止地表穿过物件传播。这是开发工具资料，不能视为所有发行版的完整战斗规则。[AI grid panel](https://docs.larian.game/AI_grid_panel)

Subset Games 官方 Into the Breach 页面确认敌方攻击预告、民用建筑供能，以及保护建筑与注意己方火力的价值。本次借鉴信息展示和战场目标，不据此臆造该游戏具体元素规则。[官方介绍](https://subsetgames.com/itb.html)

设计推断：互动价值来自改变局面、移动目标、利用结果与承担代价。本项目无需复制完整元素矩阵、双护甲或祝福／诅咒系统。

## 2. 从少量互动建立打法

油火用于有限封路，水用于救援和改变视线，湿润配雷在后期提供跨角色机会。普通佣兵也能使用油具、火种、水具，消耗补给与行动点；场景玩法不由法师独占。

| 研究选项 | 玩家价值 | 代价与反制 |
| --- | --- | --- |
| 油遇点火 | 制造局部危险、改变通路 | 消耗工具，敌我和平民同受影响，水可清除 |
| 水灭火 | 开通撤离路线、救援 | 水具有限；是否产生蒸汽需要视线实现与可读性验证 |
| 湿润遇雷 | 跨角色准备与利用 | 消耗湿润，只附加一次效果；不整片水无限传导 |
| 冻水与融冰 | 改变路径成本 | 冰增加移动成本，避免随机滑倒和连续硬控 |
| 破桶与木路障 | 铺地、开侧路、损失掩体 | 消耗攻击，也可能毁坏任务物资 |
| 阀门／固定机关 | 改变有限路线和救援窗口 | 必须接近操作；保留退出或失败结算路径 |

研究中的低成本备选是“水只灭火、不生蒸汽”，也可让湿润后的震荡仅影响下一次移动。当前主案选择前 12 周加入蒸汽遮挡以强化视觉与地形价值，暂缓单位湿润；后期雷击采用一次派生伤害。这些是替代方案，不能叠加实现。若预览或 AI 成本不受控，再退回简化版。

## 3. 必须先写清的规则

**分层。** 基础地形与通行、每格主要地表、区域效果、单位状态、物件分别存储。地表灭火不自动消除已离开该格的单位状态。首批火区不再额外附加人物燃烧，避免重复持续伤害。

**输入顺序。** 明确直接伤害、物件破坏铺设、一次反应、位移与进入格、获准被动的阶段。火打破油罐允许本次点燃；冰变水不会用同一次火输入再次化为蒸汽。生命归零立即终止相关主动触发。预览使用同一规则，动画不能决定顺序。

**期限。** 用明确全局轮次显示到期，末位单位制造的效果也应有可用时间。刷新不叠加同轮伤害。地图预置与技能生成地表可以有不同期限，但须明示；保存与加载不能延长效果。

**位移与友伤。** 推拉逐格验证，不穿墙、占用格或地图边缘，停止在最后合法格。首版不额外撞击或坠落秒杀。强制移动触发经过格危险，不触发脱离反击；主动移动仍有控制区域约束。单位每轮火区接触伤害有上限，避免反复推拉倍增。

**来源与连锁。** 同一次行动及派生结果共享根来源；同一专长对同一目标每根行动至多触发一次。派生伤害默认不再触发直接命中专长；超规格内容在校验时拒绝，运行防护需记录错误，不能静默丢弃必要结算。

## 4. 预览、AI 与表现

预览包括路径、位移落点、地表变化、友军与平民风险、行动成本、持续时点；随机命中显示成功与失败分支。油、水、火、蒸汽以纹理与图标区分，特效不遮住格子。

AI 与玩家共用合法性和预测规则，评分考虑友伤、下一回合危险、护送目标、撤离路径、灭火收益和掩体变化。先会避险和完成一步联动，再扩展多角色组合搜索。

## 5. 验证矩阵与扩展门槛

| 维度 | 覆盖场景 |
| --- | --- |
| 顺序 | 油→火、水→火、火→水、火击破油罐；后续再加湿润→雷 |
| 重复 | 重入、多格移动、两次推动、回合开始、刷新期限 |
| 空间 | 门两侧、地图边缘、狭道、物件范围、占用格 |
| 对象 | 敌友、平民、后续战犬、抗性单位、死亡对象 |
| 生命周期 | 生成当轮、轮末、跳过动画、存读档、明确期限 |
| 可玩性 | 同预算纯武器与混合队都可完成，不强迫每战使用元素 |

最大风险是元素压倒武器、硬控取消敌人行动、随机地表制造无解开局、图标过多。每新增反应都配反制和含友军风险的验证遭遇；扩量前先确认预览与实际一致、AI 能合理避险、任务仍有退出或失败结算。

风向、毒、祝福、自动蔓延、桥梁坍塌和整图破坏留在候选池。它们会改变寻路、目标可达性与制作成本，不应当作普通视觉效果随手加入。

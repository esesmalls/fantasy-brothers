# 人物成长与命运设计

日期：2026-09-19。状态：**研究与设计提案，尚未实施**。当前可玩版仍为 0.1.4。依据用户 U22、U23 和 [九篇官方开发日志研究](research/character-development-findings.md)。用户随后提出繁衍与童年教育，最新明确暂不完善系统、以约60–80游戏日对应15年作为成长参照；见 [家庭与代际传承候选](14-family-and-legacy.md)。

## 1. 体验目标与边界

用户已确认：人物有属性和等级成长，出身、职业、天赋影响起点，战斗、训练和随机经历影响后天；无论出身，都可以持续培养并塑造个性。永久死亡、伤残和性格变化构成重要后果，部分不利变化能在合适用法下产生价值。

本方案建议：**出身决定从哪里开始，培养决定能担任什么，经历决定以怎样的方式战斗。** 让玩家记得“这是我带出来的人”，同时保留失去他的风险。

“人人可培养”指每名常规人类都有实际可达的战斗岗位、公开的成长路线和持续发展空间，贫困与没有对应天赋不能永久阻止学习。它不保证同样投入立刻相等、任何伤势都没有影响，或一个人能同时精通全部流派。偏重方向、付出的时间、装备搭配和团队职责继续形成差异。

以下属性清单、等级节点、技能及训练规则都是试验建议；不视为用户已批准数值。本轮不改引擎、存档或游戏包，也不自动启动所有后续阶段。

## 2. 对照现有工程

| 0.1.4 实际行为 | 本次建议补足的关系 |
| --- | --- |
| 有生命、甲、行动点、攻击、命中、射程；初值来自岗位模板 | 拆出人物基础、后天训练、装备与当场修正，说明每点属性的来源 |
| 胜利后选一名存活者生成已保存三选一；现有五种专长 | 所有合格参战者累计经验；个人升级与专长选择；现有随机奖励接入同一成长体系 |
| 人类武器自由换装，武器决定动作与射程 | 成长资格跟随实际技能前置和训练，不能仍由原岗位锁死 |
| 0 血即永久死亡，有纪念记录与补员；当前存活伤势是生命损耗 | 永久死亡保留，后续另建重伤、急救、休养与伤残实例 |
| 脸伤和表情随实时血量变化 | 持续疤痕、包扎与性格相关表情读取真实规则状态，不伪造心理数值 |

代码审查重点：`campaign_rules.gd` 的 `_new_unit/_generate_growth/_eligible_perks` 仍依赖 `kind`；弓手拿长枪可以攻击，却不能像原枪手那样学习破阵。猎人指挥能力也仍查 `kind`。装备直接差量改最终攻击/命中，尚无基础属性账本。当前没有 XP、等级、训练、永久伤残或性格模型。

## 3. 人物构成与属性

### 七种信息各负其责

| 构成 | 作用 | 约束 |
| --- | --- | --- |
| 出身 | 农活、护送、抄写、牧养等既往经历；初始熟练度、知识和事件入口 | 不用社会阶层限定属性上限；事件专业知识也能通过学习取得替代入口 |
| 初始职业经历 | 表示过去练过什么；如护卫较早会用盾，牧人已有照料动物的经验 | 不把“当前职业”变成不能换装或转向的硬职业 |
| 天赋倾向 | 少量擅长方向，降低该方向的部分学习成本 | 不设“无星就练不成”；不复利放大每次升级收益，不额外抬高专属上限 |
| 基础属性与训练 | 决定稳定战斗能力，可查看来源和下一训练目标 | 统一计算，避免换装吞掉成长或重复加成 |
| 学会的能力 | 武器专长、战术、驯兽、后续法术等 | 前置主要是已学知识/训练；背景可以提前拥有，但非终身独占 |
| 性格与关系 | 决定对什么事在意、什么处境容易动摇、怎样建立配合 | 不替玩家无预告地抢走控制；与即时士气分离 |
| 伤势与履历 | 记录真实身体代价、转折和个人故事 | 已发生历史不因洗点消失；伤残不是另一种可无限收集的装备 |

### 属性建议

先整理以下有明确战术用途的属性；不为了面板完整而一次做齐：

| 属性 | 玩家可感知用途 | 实施建议 |
| --- | --- | --- |
| 体魄 | 生命上限、承受严重伤势的余地 | 首批；当前阶段只连接生命，不提前显示未实现的伤残阈值 |
| 近战技艺 | 近战命中与相应训练资格 | 首批；从通用命中中拆出，并审查与装备加成的预算 |
| 远程技艺 | 射击命中与相应训练资格 | 首批；弓手转长枪不会丢失原有弓术 |
| 防御技艺 | 提高保命和阵线能力，为低输出人物提供战术职责 | 首批只验证一个统一防御值；盾、掩护、破绽等修正仍单列 |
| 意志 | 面对压力、恐惧和鼓舞的稳定程度 | 与士气一起上线；勇敢不等于必然善良、鲁莽或免疫恐惧 |
| 耐力 | 护甲负担、连续行动及恢复的取舍 | 后置疲劳模块；不与当前每回合 6 AP 混用 |

武器提供基础威力、射程和动作，防具提供护甲及其耐久。AP 暂保持当前节奏，不随升级无限增加。先手/速度、独立力量、魔力等只有在相应规则产生独立价值时才加入；魔法长期允许经学习获得基础入口，特殊契约或变异可改变代价与表现，不按贵族血统统一封锁。

训练基础值使用所有人共享的目标区间与递减收益。背景提供小幅起点差或已完成的入门训练；达到共同训练基准后，起点差不继续复利。天赋提供有限的学习便利，不压缩普通人的必要学习次数到无法接受的程度。

不把防御、生命、命中和输出做成可无成本兼得的全满面板。角色在主要成长阶段需要选择有限的训练重点；后期转向仍有通路，但要付时间和再训练成本。最终强度需要对照当前命中上下限重新预算，不能机械叠加现有“精准 +8”。

## 4. 升级、训练与随机经历

### 一条可规划路线，几次值得记住的转折

建议沿用原方案的 1–8 级作为首轮验证区间，2/4/6/8 级作为关键能力节点，**这是测试尺度，非最终等级上限**。

- 普通升级：获得可预览、确定的属性训练选择。先试每次强化两个方向；弱项可以补足，不能因升级随机数长期练不成。
- 关键节点：玩家选培养方向，至少保留一项保证可学的基础能力；经历与当前构筑再提供少量候选。未取得前置装备时说明取得路径，并允许延后选择。
- 高等级：有限的深造、替换已选专长、学习另一战术的入口；不给无限专长位和持续膨胀的 AP。能继续培养，与迟早全能，是两件事。
- 随机事件：改变机会、学习途径、关系和代价。核心岗位能力能稳定学到；稀有机遇可以形成特别玩法，但不得成为整条基础流派唯一入口。

### 经验与训练建议

参战者分享一次结算的任务/遭遇经验，不让补最后一刀决定谁成长。护卫、控场、侦察和战犬协作都能成长。击杀、受击、反复放火和拖回合不逐次产生可无限刷的经验；低风险重复任务的高阶成长收益受限。

失败或有序撤退的幸存者也可获得与已完成目标有关的有限经历；不发胜利奖励。死亡者保留履历，不再分配可消费升级。出战名单和任务进度在结算前已有记录，不能通过事后换人领取。

营地训练选择一名角色和一个明确目标，显示需要的天数、口粮、导师条件与所得。基础操练不要求昂贵教师或罕见道具；付费教官主要节省时间或提供专门课程。训练所需实践额度来自有效任务，普通等待不能无限把新兵练到顶。

新兵具有有限的基础补课额度；完成任务可补充进一步实践额度。落后队员在共同入门基准以下有追赶训练，超过基准回归正常速度。精确次数需要试玩验证，不能用“总有一天能练成”掩盖漫长枯燥。

先不按出身给贵族终身更高属性、给穷人终身更低薪等相互强化优势。招募成本应反映现成技能和装备；薪酬逐步对应当前能力与履历。团内导师可带新人，但名额有限，指导也占用导师的营地安排。

### 成长必须改变战斗方式

以下是用于挑选小样本的原创技能候选，不是本轮新增功能。先做其中一至两项，复用已有护卫、破绽、元素和战犬系统。

| 候选 | 玩家价值与代价 | 反制、限制与可见表现 |
| --- | --- | --- |
| 护送换位 | 花行动点与相邻自愿友军换位，救出被围队友或让枪手接替阵线 | 两格必须可合法占据，不穿障碍；危险地表与脱离威胁按统一规则处理；每人每回合限一次，预览双方终点与危险 |
| 拒进架枪 | 花行动点放弃追击，在有限前方格等待一次拦截，保护弓手与通道 | 到本人下回合失效；只触发一次，不返还 AP；敌人可绕行、远射或推离枪手；明确标出拦截格 |
| 雾中掩护 | 使用有限水资源制造原有蒸汽遮蔽，帮助队友脱离远射，并与后排换位配合 | 自己也受遮挡，不额外创造命中或伤害免疫；范围与持续时点可预览；不突破现有元素触发上限 |
| 交替追猎 | 具备后天驯兽训练者用指令安排战犬与长枪接力控制一个目标 | 消耗主人行动机会；犬存活、距离、行动资格均需满足；不能通过反复标记刷新同一轮收益 |

主动能力的意义是新增一个决策，而非叠加许多同义按钮。武器基本招式、随身物品、已装备战术分区；成熟阶段每人常用主动技能目标仍为 4–6 个，现有战具与战犬指令另按上下文收纳。反应统一记录根行动、次数和期限；敌人也遵循公开的范围与触发规则，特殊免疫有明确图示。

## 5. 死亡、伤残与适应

### 分清四类后果

1. **生命损耗**：当前已存在的即时危险，治疗可以恢复。
2. **暂时伤势**：例如拉伤、裂口，影响若干天；回复生命不等于伤势痊愈。首次样板只做一种，明确预计恢复时间和继续上阵风险。
3. **永久伤残**：持久的身体改变；可以调整打法、学习适应、使用装备补偿。保留真实机会成本，不要求每种伤残都有天赐加成。
4. **永久死亡**：人物离开名册战力，成长和关系不能原样继承给替补。纪念册保存其来历、关键经历与结局。

### 后续重伤救助候选

当前 0 血即死的规则本轮不变。引入重伤时必须一次设计完整状态链：可救重伤 → 无法行动/可被救助 → 稳定并带离或失救死亡 → 战后一次清点伤势。明确不可救的伤害条件也必须由规则预告，不依赖动画猜测。

救助花同伴行动、医疗资源和阵线安全；敌人接近、地表危险、撤退时机都能形成选择。稳定不等于立即恢复战斗，更不等于任何情形必定生还。随机结果若保留，风险范围需预告，生成后保存；再次开结算或读档不能再掷一次。

伤残与战死在同一次结算内互斥。不能简单把旧档 `hp == 0` 改解释为可救伤员，更不能使纪念册中的人复活。

### 不利变化的价值来自打法与选择

| 示例候选 | 明确代价 | 可发展的方向与玩家决定 | 避免成为刷奖励 |
| --- | --- | --- | --- |
| 膝部旧伤 | 连续长距离位移代价增加，追击更困难 | 休养和步法训练后转为短步换位、守隘枪手；敌人绕行时仍吃亏 | 拒进等技能健康人同样可学；旧伤不免费送专长或取消移动代价 |
| 持续视力损伤 | 远距离瞄准受限 | 调整为近距射手、盾手或协作指令角色，学习观察标记目标的稳定打法 | 近距课程是通用学习路线；不以失明换取超常精准，也不把所有伤员赶去后勤 |
| 对火场心有余悸 | 临近火区时士气更易受压，火场突进不适合 | 安排控水与外圈救援；付时间练应对，准备水囊、留退路 | 火场救援知识可以正常训练；自烧、友伤不累加有利经历；此项属于经历/心理变化而非身体伤残 |
| 谨慎多疑 | 跟陌生伙伴合作时部分配合难以充分发挥 | 适合斥候和风险识别，持续同队建立信任后可形成稳定配对 | 相关优势只在明确风险判断出现，不永远加命中；重复招退新人不刷奖励 |
| 固执守诺 | 违背已经接受的誓约会带来可预告的情绪代价，临时改变部署可能牺牲准备效果 | 擅长守点与保护约定对象，也可在营地重新协商承诺 | 守诺效果绑定合法目标和期限；不通过自建/撤销承诺叠加，不强制角色自行冲锋 |

“失去什么”与“还能练什么”同时显示。恢复训练帮助找回主动权，**损伤自身不必有正面效果**。在相同训练投入下，主动制造伤残不能获得独占的强力能力；重复伤害最多恶化已有状态，不能刷出越来越多补偿。严重损伤可能结束某一战斗路线，尊重其代价，也给其他战斗职责和自愿退休留下空间。

未来奇幻义肢、赐福和变异进入候选池：用昂贵维护、装备占位或契约代价换一种能力，并保留正常学习的可行玩法。它们不能成为普通伤员唯一出路，也不在基础系统未稳前铺开。

伤残上线的配套条件：至少有可用替补、可负担的治疗、能带伤完成的低风险工作、退出高风险契约的路径。先验证当前四人队的容错，再决定是否增加两个后备位；没有这些配套就暂不上高频重伤，防止一次失败变成连续失败。

## 6. 性格、关系与人生轨迹

**意志是能力，士气是此刻状态，性格是长期倾向，关系是两个人之间的经历。** 各自独立，UI 按需展示。勇敢的人也会悲伤；谨慎的人也能在准备充分时完成救援。

先用少量可描述的特质标签，不建十几条隐藏人格轴。性格变化来自重大事件与反复出现的真实选择，单次普通受击不随机洗性格。事件提前呈现人物在意的事情，营地提供应对：安抚休养、选择训练、承认代价或调整职责。玩家可以引导但不能零成本改成全员同一性格。

例如“受救之后”可以走向愿意保护同伴，也可以走向更审慎、重视退路；没有一个必选正确答案。每条转变分别定义获得/失去的机会、触发范围和缓解方式。不把创伤直接等同于怯懦、邪恶或人格缺陷。

与现有旅行—事件—战斗—返营接法：旅行暴露人物习惯，契约提供价值冲突，战斗记录关键行为，返营决定怎样消化经历，下次出征验证改变。首批只选择一组同伴关系和一个转折事件；冷却、门槛与已触发标记保存，剧情中的人物死亡或缺席时走替代路径。

一个原创成长样例：农家出身的阿洛初来只会基础长枪 → 参战与操练逐渐能守住阵线 → 在火场护住队友，返营选择救援训练 → 后来膝部留下旧伤 → 玩家为他换盾、调整站位，学短步换位，成为护送队友的老兵。他的面孔、装备、打法和履历持续相连。也可以不发生伤残，或在救援中永久阵亡；它是一种可产生的故事，不是指定角色必走剧情。

阵亡影响同伴和佣兵团记忆，但不让悲伤全队无限叠加崩溃。导师与营地设施可以帮助后来者学习，不能完整复制死者等级、所有专长和人际关系；遗产不得使主动牺牲队员成为经济/成长最优路线。

## 7. 表现与信息组织

- 人物页优先呈现：姓名/出身、分层肖像、战斗职责、等级进度、主要能力、当前伤势、下一训练目标。数值悬停再解释基础、训练、装备、伤势和临时修正。
- 战场底部继续围绕当前角色；浮动详情列出会影响本次动作的状态与恢复条件。全局性格资料留在人物页，不长期覆盖战场。
- 头顶小图示表达已存在的危险、动摇、坚守或关系配合，只有状态变化时短暂表情/短语；玩家能通过悬停知道具体原因与规则。
- 伤势表现使用稳定部位与伤势 ID：即时流血、疗养包扎、愈后疤痕分层。头盔可以遮住伤疤，但详情仍可查看；装备不随脸部表情变形或替换角色身份。
- 当前程序绘制仅有 HP/护甲反馈，不能提前声称永久疤痕、士气或心理活动已接入。

## 8. 工程接入建议与验收

第一步先建立人物属性来源账本。建议用稳定的 `species_id/background_id/capability_tags` 拆开 `kind` 的物种、过去岗位和能力职责；旧战斗的 `kind` 回退保留到其结束。

`base_stats` 存基础，`progression` 存经验、等级、训练增量和已学能力，`injuries/traits/history` 存明确实例；护甲耐久仍属于物品，当前生命属于持续状态。所有来源由一处计算有效属性，统一固定修正阶段与上下限，同时产出给 UI 的来源说明。

先汇总角色基础和训练，再套装备修正、持续伤势/特质的适用项，最后计算战斗临时状态。加算、乘算、覆盖与上限必须逐项声明；本段不是允许各模块自行改变计算顺序。装备改为贡献数据，停止反复对最终命中与攻击做新旧差量写回；人物成长也不直接覆盖装备属性。

旧档迁移要求保持最终属性、装备耐久、已取得专长与故事结果。旧进行中战斗快照、行动记录与 RNG 不重算；旧 growth 候选仍按生成时版本兑现。不能从岗位猜出一套新基础再将原成长加一遍。迁移采用可审计的旧值反算/兼容分量，并覆盖 camp/event/battle/growth/returning 各阶段。

成长、伤残与性格实例至少存稳定ID、定义版本、通用来源 `source_type + source_id`、获得时间、期限/恢复进度。来源可为背景初始化、出生、教育、事件、战斗行动、训练或旧档迁移，不为家庭活动伪造战斗行动。

特征另声明 `origin_kind`（先天/背景/教育/经历/伤势等）及显式 `heritable`，默认不可遗传；来源实例继续引用实际事件或人物。未来遗传只读取定义明确允许的先天候选，不能把后天人格、创伤、武技或迁移兼容加值当作遗传标签。

结算具有唯一claim；随机机会生成即保存，独立的成长随机流不能改变当前战斗的命中序列。重放承诺限定于同一规则版本。

有意义的验收：

1. 普通低起点且无相关天赋的人物，在共同装备预算和明确训练次数下，能在至少两种培养分支达到样板战斗的合格门槛；应在接任务时就有有用工作，不要求先忍受数小时无用期。
2. 强出身节省的初期训练和风险真实可见，但不能凭出生同时压过所有后天路线；同样背景也能通过选择成为不同职责。
3. 同一人物反复换装不漂移、不丢成长；不同出身满足同一前置时具有同等学习资格；驯兽不再永久锁在原猎人模板。
4. 保存/加载/重复清点不增加经验，不重抽升级、伤势或性格；旧档迁移保留快照与原有效数值。
5. 新技能各有一种有利场景、一种反制和明确费用；连锁不能越过根行动和次数上限，预览与实际结算一致。
6. 每种伤势和个性都有可复现的代价、可理解的应对、需要的前置配套；自伤、友伤、重复低危事件不能成为最优培养法。
7. 死亡/缺席、救助失败、撤退、低资金和多人受伤时仍有合法故事与战役路径；没有死者领奖、装备复制、无限继承或旧死者复活。
8. 实际导出包验证人物页、底部 HUD、战场悬停与肖像使用同一状态。自动对战数据不能替代玩家对“舍不得这个人”的反馈。

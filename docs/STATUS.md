# 当前项目状态

更新：2026-09-19。最新可玩增量 **0.1.5.1：简洁战场悬浮信息**；人物培养基础为0.1.5。Godot **4.7.2 stable**，单一Windows工程，新战斗`prototype-0.1.5`。

## 用户当前方向

- 原创2D战棋与佣兵团经营，魔幻中世纪，战斗、人物故事和视觉反馈兼顾，长期目标Steam。
- 唯一真人每周10–20小时、三台电脑；主AI统筹，专项AI按重要性与成本分工。
- 先搭框架和功能，再扩内容；保留已认可的元素受击、战场优先HUD、射程与友军穿行。
- 大地图长期改为自主移动与自由探索；当前固定路线是过渡骨架，允许后置。
- 装备自由组合、穿戴可见并支持后续套层，伤势反映在脸和身体。当前只有武器/护甲两槽，未实现独立头盔、披风、副手。
- 出身、天赋与经历影响培养，每个人都能养成；永久死亡、伤残和性格变化提供需要决策的后果。
- 繁衍、童年教育与有限遗传属于长期候选；约60–80游戏日对应15年仅为待验证尺度，现在不完善系统。
- U26–U27：用户明确允许GitHub同步和接入属性培养；高出身未来承担更高招聘价格与维护费，具体数值未定。
- 最新U30：优先评审覆盖当前框架的美术制作方法，要求人物面容可区分、装备适配与套层、同装备损伤变体、战场地块叠加及完整UI美术；用户同意选型后，再展开详细方案和四步实现。
- 最新U31：用户已同意该方法，补充精细伤痕/元素/尸体、避免拼贴和马赛克阴影、大胆边框、技能/特质/性格/物品图标化与悬停详解；本轮明确要求写详细计划。
- 最新U32：倒下不一定代表死亡；胜利后倒地队员可能幸存受重伤。已并入第四步与美术状态机，具体概率和败退处理仍是待验证提案。

## 最新交付：美术方式已确认，详细计划已整理

已确认采用模块化手绘2D、OpenAI参考生成/编辑、分层修整与定位校准、Godot组合与UI的混合方式；SpriteCook保留可选辅助，未接入或实测。新增 [18详细美术计划](18-art-production-plan.md) 与 [设定集研究](research/art-book-findings.md)，覆盖人物/装备/伤损/尸体、战场与世界、图标与UI、现有内容清单、四步依赖、AI分工和验收。17保留为选型历史依据。

本轮阅读用户提供的60页设定集并重点检查相关完整页，另由子代理盘点现有10武器/4甲/30核心图标语义/6地点/9主要页面，制定视觉规范和独立验收建议。30是核心图标基线，完整覆盖将以所有可达规则/表现ID与页面状态清单核对。当前HP归零即死亡、尸体仍是程序叉号；用户已要求未来改为战中倒地、胜利后可能重伤幸存，计划已更新，尚未实现。

下一实施顺序：代表美术切片→当前框架完整覆盖→招聘后勤→差异契约→部署替补→倒地伤亡/人物后果→整批实际导出验收。按最新“写详细计划”请求，本轮未生成正式资产、安装或采购服务、修改游戏/存档、启动四步实现；可玩版本仍为0.1.5.1。数量和尺寸属于待样板验证的生产目标，没有画质、成本或性能实测结论。

## 最近调整：0.1.5.1

- 默认角色悬浮卡使用生命/护甲/行动点色条、数值、攻击/射程/防御图标与状态/专长徽记，宽264逻辑像素；危险状态优先，溢出提示数量。物件与地表也用紧凑摘要。
- 有悬浮目标时按一次Alt展开说明，再按收起；详细宽380、正文最高300，滚轮查看完整属性、装备、效果和期限。新战斗默认简洁，弹窗期间不响应，Alt不写存档。
- 原动作预览留在底栏；鼠标移动不被卡片抢走，点击卡片区域不执行战场动作。保留战斗数值与既有元素/受击表现。
- 用户要求的下一批四步已整理为 [批次计划](16-next-four-steps.md)：招聘后勤→差异契约→出战替补部署→伤势/伤残/性格样本。可以一次交付，但按依赖串行开发验证；本轮未实现这四套新规则。

## 人物培养基础：0.1.5

1. 营地与地图营地入口新增「人物帐」：出身、经验、等级、属性来源、已学本领与履历。人物/军需两页保留同一队员互相跳转。
2. 体魄、近战技艺、远程技艺、防御实际参与战斗。来源账本统一培养、专长和装备；反复换装不重复加成，提升体魄保留伤血，甲损继续跟随实例。
3. 个人1–8级：累计每100经验升级，每级2培养点，营地自主分配。胜利存活参战者100经验，有效交战后败退35；立即逃跑、纯移动/等待/空犬指令不奖励。一次结算不能重复领取。
4. 人类基础训练花1天、1粮、1实践额度，四项可选；初始1额度，有经验的战斗补充、上限3。学习驯兽额外12金，各人类出身共享资格。
5. 长枪手等可以学驯兽、接管现有战犬，在实际战场使用标记与指令。每犬单一主人，行动次数不增加；旧岗位不再锁死人类破甲专长。犬保留经验/等级履历，但不发尚无消费用途的人类点数/额度。
6. 原战后三选一专长、死亡与装备损失、旅行—事件—契约—返营生活继续存在；元素与受击反馈保留。
7. 旧0.1.4多阶段战役自动迁移，旧专长/装备/伤血精确保留；0.1.4和0.1.1进行中战斗完整快照及RNG不变，下次出征再用新规则。

操作与数值见 [试玩说明](PLAYTEST.md)、[已实现人物规则](15-character-attributes.md)。更完整的伤残/个性/天赋方案见 [13](13-character-progression.md)，代际方向见 [14](14-family-and-legacy.md)；研究提案不等于已实现功能。

# 当前项目状态

更新：2026-09-19。当前增量 **0.1.2**：战场优先的战斗界面与悬浮信息。Godot **4.7.2 stable**，单一 Windows 工程；战斗规则仍为 prototype-0.1.1。

## 当前用户方向

- 原创 2D 战棋与佣兵团经营，魔幻中世纪，战斗、故事与视觉兼顾，长期目标 Steam。
- 用户一人，每周 10–20 小时，三台个人电脑开发。主 AI 担任总监，按重要性、难度和成本安排专项 AI。
- **先搭整体框架和功能，再逐步丰富内容。** 每项仍用少量代表数据验证可玩、存档、失败和后果。
- 用户已试玩认可 0.1.1 修复、现有剧本、元素效果和受击反馈。
- 新要求：战场几乎铺满屏幕；人物、技能、道具、行动顺序置底；详情悬停查看；左上战报。氛围图示服务于人物与战场。
- 大地图承载佣兵团探索、生活和工作，肉鸽事件进入旅途、契约和战斗。

## 本次玩家可以感受到的变化

1. 移除战斗右侧常驻信息栏，战场画布覆盖视口，底部集中当前人物生命/护甲/行动/攻击/射程、招式、全团共享战具和回合操作。
2. 底部行动顺序从当前单位开始，区分敌我、标出下轮并过滤死亡者；悬停名字也能查看详情。
3. 鼠标移到敌我人物上身/底座、战犬、物件或地表即可查看详情。包含真实属性、状态来源与期限、专长、犬指令、物件耐久/毁坏后果、油火水汽；敌人回合仍可查看。
4. 左上角显示最新战报，展开后可滚动看完整记录；上方只保留轮数、人数和目标。
5. 加入原创招式/岗位图标、盾形等状态提示、基于已有危险的短语。保留油火、水汽、受击动画、速度选择、当前行动标识、友军通行及射程预览。
6. 人物点击轮廓按头部、躯干和底座细分，避免透明空白截获相邻格。HUD 拦截点击，悬浮信息避开底部操作区。

本次没有新增士气或隐藏心理数值，也未改变战斗平衡、存档结构或路线代价。

## 已有闭环

两类佣兵团、各四出战位；营地休养/补给/修甲/补员和缺钱恢复；两条有代价预告且保存选择的路线；六个有条件及缺席路径的事件；六边格、6 行动点、护甲/生命、控制区反击、盾枪联动、远程和敌方 AI；油火、水火蒸汽、可破坏物件和粮仓目标；战犬跟随/牵制/撤回；胜败撤退、永久死亡、成长三选与空池回退；三次远征短篇收束后可继续。

自动/手动档保存战场、随机状态与候选，主档损坏尝试完整备份。0.1.2 沿用 0.1.1 存档和规则；有效 0.1 旧档按既有迁移保留进度。未取得另两台真实个人旧档逐份检验，不宣称跨规则版本重放相同。

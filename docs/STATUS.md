# 当前项目状态

更新：2026-09-19。本轮增量 **0.1.4：装备库存、自由武器组合与分层人物**。Godot **4.7.2 stable**，单一 Windows 工程；新战斗规则 prototype-0.1.4。

## 用户当前方向

- 原创2D战棋与佣兵团经营，魔幻中世纪，战斗、人物故事和视觉反馈兼顾，长期目标Steam。
- 用户一人、每周10–20小时、三台电脑；主AI拆任务/集成/交付，专项AI按重要性与成本分工。
- **先搭框架和功能，再扩内容。** 保留已认可的元素受击、战场优先HUD、射程与友军穿行。
- U20：大地图长期改为自主移动、自由探索，事件随旅途发生；当前固定路线是过渡骨架，允许后置。
- U21：装备必须与人物自由组合、穿戴可见、可扩展套层，脸和身体反映真实伤势；这是基础结构要求。

## 本轮已接入

1. 营地「军需帐」：选队员、查看实际装备与属性、采购、换装和出售。交易/换装自动保存，查看不耗时或重抽。
2. 人类跨岗位组合现有剑盾、长枪、弓、短兵、猎弓与护甲。武器决定招式和射程，人物kind保留背景/成长；猎人换剑盾后仍能指挥战犬。
3. 稳定物品实例、武器/护甲槽和装备定义分离；换装后旧物入库。护甲损耗跟随实例，换下再穿不会免费修复。
4. 配发品不予回购，已装备不能直接出售，购买品售价低于购价。阵亡者随身装备丢失，备用物品保留；补员费用内配发基础装备。
5. 修补覆盖随身、备用护甲和存活战犬；按总损耗每4点1金向上取整。缺钱用一天全团总共修最多6点，优先随身与犬，再库存。
6. 营地肖像与战场共用原创分层绘制。人物ID保持面孔身份，实际甲、武器/盾、甲裂损与脸部伤势可见，低血量有痛苦眉嘴变化。头盔/披风等独立装备槽位后续扩展，本轮未实现其套层结算。
7. 原旅行—事件—契约战斗—成长—返营生活继续可用。旧档补装备映射；旧0.1.1进行中战场保留其版本、原快照/RNG与行动记录，按kind回退原动作；新出征采用0.1.4规则。

## 当前边界与下一候选

当前仍为六地点、两条聚合路线、单个重复契约；没有自由走图、追逐、多战场或随机契约池。仅两种装备槽，剑盾暂为一件组合武器，尚无独立副手、头盔/披风、重量疲劳或完整装备套层防护。表情只反映真实血量，不存在新士气/隐藏心理数值。仍无声音与商业美术；未覆盖另两台电脑和每份真实旧档，手感/平衡需真人试玩。

下一候选是契约与遭遇数据化；装备套层和自由探索已进入明确后续方向。先收集本轮试玩反馈，不自动并行启动所有系统。见 [10-framework-roadmap.md](10-framework-roadmap.md)。

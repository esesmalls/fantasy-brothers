# 当前项目状态

更新：2026-09-18。当前增量 **0.1.1**：完成三项上午试玩修复，接通两条远征路线；固定 Godot **4.7.2 stable**，单一 Windows 工程。

## 当前用户方向

- 原创 2D 战棋与佣兵团经营，参考《Battle Brothers》的体验；魔幻中世纪，战斗、故事与视觉兼顾，长期目标 Steam。
- 用户一人，每周 10–20 小时，三台个人电脑开发。主 AI 负责总监、接口与集成，专项 AI 按难度、重要性和成本分配。
- **最新顺序：先搭整体框架和功能，再逐步丰富内容。** 每项功能仍用少量代表数据验证可玩、存档、失败和后果。
- 战役持续成长，远征事件与奖励变化，失败保留伤亡和损失。
- 用户已认可现有元素效果和受击反馈，保留并逐步丰富。

## 本次玩家可以感受到的变化

1. 当前行动者显示前景双环、箭头和「姓名 · 岗位」，敌人和战犬也有标识；战斗结束后隐藏。
2. 同阵营单位及战犬可作为移动中间格，不能重叠停留；敌人、物件和障碍继续阻挡。逐格付行动点，火区和脱离反击照常结算。
3. 选择攻击或技能即显示射程、遮挡和合法目标，悬停显示波及；动作按钮标注格数。切回移动或结束战斗会清除攻击范围。
4. 营地选择「渡口旧道」或「山脊险径」，预告粮食、天数、敌情、报酬与补给；路线、代价与历史保存。目前复用同一粮仓战场。
5. 移动途中被火区/反击击杀后自动推进到下个活人，连续回合开始火区死亡也能处理；解决 AI 卡回合和死亡动作自动存档失败。

旧道沿用 2 粮/1 天与原难度报酬；险径 3 粮/1 天、难度 +1（最高 2）、报酬 +18 金、油 +1。第五次远征后基础敌情可能封顶，两路风险相同时界面明确说明实际补给/收益取舍。数值仍是原型假设。

两类佣兵团、各四出战位；营地休养/补给/修甲/补员和缺钱恢复；六个有条件及缺席路径的事件；六边格、6 行动点、护甲/生命、控制区反击、盾枪联动、远程和敌方 AI；油火、水火蒸汽、可破坏物件和粮仓目标；战犬跟随/牵制/撤回；胜败撤退、永久死亡、成长三选与空池回退；三次远征短篇收束后可继续。

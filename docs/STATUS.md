# 当前项目状态

更新：2026-09-19。最近可玩增量 **0.1.4：装备库存、自由武器组合与分层人物**；最新工作为人物成长与传承研究，未改游戏版本。Godot **4.7.2 stable**，单一 Windows 工程；新战斗规则 prototype-0.1.4。

## 用户当前方向

- 原创2D战棋与佣兵团经营，魔幻中世纪，战斗、人物故事和视觉反馈兼顾，长期目标Steam。
- 用户一人、每周10–20小时、三台电脑；主AI拆任务/集成/交付，专项AI按重要性与成本分工。
- **先搭框架和功能，再扩内容。** 保留已认可的元素受击、战场优先HUD、射程与友军穿行。
- U20：大地图长期改为自主移动、自由探索，事件随旅途发生；当前固定路线是过渡骨架，允许后置。
- U21：装备必须与人物自由组合、穿戴可见、可扩展套层，脸和身体反映真实伤势；这是基础结构要求。
- U22–U23：属性、升级、技能、出身与后天培养深化；每个人都能养成。永久死亡、伤残和性格变化带来可决策的后果，部分负面变化在合适用法下有价值。
- U24–U25：长期探索繁衍、童年教育与部分父母特征继承；现在不完善系统，约60–80游戏日可对应15年成长，具体数值待验证。

## 最新研究与建议（未实施）

已阅读用户指定的2014年1月两篇及另外七篇Battle Brothers官方日志，并核对CK3官方介绍、RimWorld Biotech官方成长预览。资料与原创判断分开，见 [研究记录](research/character-development-findings.md)、[人物成长与命运](13-character-progression.md)、[家庭与代际传承](14-family-and-legacy.md)。主AI统筹，两名Sol子代理分别只读审查工程与内容；本轮只改文档，没有新增游戏验证或导出包。

实际差距：当前仍是岗位初值、胜利后单人三选一专长，尚无经验/等级/训练/伤残/性格模型。人类可以自由换武器，但部分专长与猎人能力仍被kind锁定。建议优先做统一属性来源、个人成长与一条普通人可规划培养路线，再以少量样本接伤残和性格。

繁衍与教育进入长期候选：遗传少量特点，教育塑造主要方向；亲生、收养与导师培养共用规则。按用户给出的游戏日换算验证时间，成长独立于危机是否触发；成年老兵的衰老节奏需另行评估。当前不改日历、存档或生成儿童。

## 最近可玩增量：0.1.4

1. 营地「军需帐」：选队员、查看实际装备与属性、采购、换装和出售。交易/换装自动保存，查看不耗时或重抽。
2. 人类跨岗位组合现有剑盾、长枪、弓、短兵、猎弓与护甲。武器决定招式和射程；kind仍表示原岗位并参与部分成长/猎人能力判断，尚未完整拆分。猎人换剑盾后仍能指挥战犬。
3. 稳定物品实例、武器/护甲槽和装备定义分离；换装后旧物入库。护甲损耗跟随实例，换下再穿不会免费修复。
4. 配发品不予回购，已装备不能直接出售，购买品售价低于购价。阵亡者随身装备丢失，备用物品保留；补员费用内配发基础装备。
5. 修补覆盖随身、备用护甲和存活战犬；按总损耗每4点1金向上取整。缺钱用一天全团总共修最多6点，优先随身与犬，再库存。
6. 营地肖像与战场共用原创分层绘制。人物ID保持面孔身份，实际甲、武器/盾、甲裂损与脸部伤势可见，低血量有痛苦眉嘴变化。头盔/披风等独立装备槽位后续扩展，本轮未实现其套层结算。
7. 原旅行—事件—契约战斗—成长—返营生活继续可用。旧档补装备映射；旧0.1.1进行中战场保留其版本、原快照/RNG与行动记录，按kind回退原动作；新出征采用0.1.4规则。

## 当前边界与下一候选

当前仍为六地点、两条聚合路线、单个重复契约；没有自由走图、追逐、多战场或随机契约池。仅两种装备槽，剑盾暂为一件组合武器，尚无独立副手、头盔/披风、重量疲劳或完整装备套层防护。表情只反映真实血量，不存在新士气/隐藏心理数值。仍无声音与商业美术；未覆盖另两台电脑和每份真实旧档，手感/平衡需真人试玩。

最新建议将人物成长基础提到契约扩量之前；契约/部署仍需为伤残休养与替补提供配套。装备套层、自由探索和代际培养继续分阶段评估。此次请求为分析扩充，尚未启动下一实现增量，不自动并行铺开所有系统。见 [10-framework-roadmap.md](10-framework-roadmap.md)。

# 当前项目状态

更新：2026-09-19。当前增量 **0.1.3：旅行—事件—契约战斗—返营生活**。Godot **4.7.2 stable**，单一 Windows 工程；战斗规则仍为 prototype-0.1.1。

## 当前用户方向

- 原创 2D 战棋与佣兵团经营，魔幻中世纪，战斗与故事兼顾，长期目标 Steam。
- 用户一人、每周10–20小时、三台电脑开发；主 AI 拆任务、集成和交付，专项 AI 按难度与成本分工。
- **先搭整体框架和功能，再丰富内容。** 用户已认可此前战斗界面、剧本和元素受击反馈，明确授权本轮接通旅行闭环。
- 保留全屏战场、底部人物/技能/道具/顺序、悬停详情和左上战报。

## 本次玩家可体验

1. 六处固定地点的边境地图：团旗显示当前位置，路线区分已走与未走，点击已发现地点查看见闻。
2. 比较两条路线并接取雨夜粮仓契约，逐站行军，在实际地点触发既有事件。第三次远征实际经过裂钟桥头。
3. 旅行、事件和准备阶段可查看行程；浏览地图不扣费、不推进、不重抽。
4. 契约战斗后清点伤亡与奖励，完成成长，再明确返营，进入休养、补给、修甲、补员生活，随后可以再次出发。
5. 保存地点、行程、事件实例和选择；防止重复领奖或跳过战斗直接结算。旧版进行中的事件、战斗、成长保留原进度。

去程仍为旧道2粮/险径3粮、1天，一次扣除；逐站不重复扣。战斗结算保留既有1天，返回不额外收费或领奖；零资源及全员死亡可返营恢复。已保留既有六事件、两佣兵团、战犬、永久死亡、成长、元素互动与三次远征短篇。

## 边界与下一步

本轮是六地点、两条聚合路线和一个可重复契约的功能骨架；尚无任意选边自由行军、随机开放世界、随机契约池、多战场、装备库存/交易或战中事件。地图仍为原创程序美术，无音频。自动检查不替代真人趣味、手感和平衡评估；另两台电脑/显卡与真实个人旧档未逐份验证。

下一候选为库存/装备/换装与交易，之后扩契约与遭遇；等待本轮试玩反馈，不自动启动下一项。实施记录见 [11-world-map-framework.md](11-world-map-framework.md)，候选顺序见 [10-framework-roadmap.md](10-framework-roadmap.md)。

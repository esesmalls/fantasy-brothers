# H 静态半身：穿戴与武器反馈标准

2026-09-20，U47修订。主AI独立制作、集成和审阅，未启动子智能体。

## 已采用的方向

U46选择回归Battle Brothers式静态半身：取消手和拼装手臂，头身独立、低底座、衣甲遵循同一构图。U47认可总体画风与动作，修订为更小的头、身体与脸同向、自然截取的短上臂和衣袖、较轻底座与较大武器。H仍为画风基准；Spine／三维降二维仅作未来候选。

“无手”不等于只保留肩头。应保留短上臂，使衣袖顺着身体自然垂落；不能为了塞进底座挤压腋下、把衣甲收成圆垫。没有前臂、手掌或局部肢体骨骼动画。

最新[评审页](../art/validation/2026-09-20-static-bust-v2/index.html)、根目录 `Review-Static-Bust.cmd` 和Windows独立导出展示一人、两甲及甲损、独立脸伤、剑盾/枪/弓与绘制命中效果。正常战役仍为0.1.5.1，新人像尚未批量替换全部单位。

层序：底座 → 身体 → 亚麻 → 绗缝 → 链甲 → 独立头 → 盾 → 武器/箭。头沿下颌分离，颈根属于身体，面容位于衣领之前。U47基础身体穿素色贴身内衣，不标为裸胸；旧 `bare` 标识保留内部兼容，界面显示“基础内衣”。

采用完整透明衣甲，不把领肩、袖口裁成矩形补丁盖缝，不借旧A手臂拼接。图集隔距不足时重新生成，不裁去肩尖。索引工具只读取PNG并写几何配置，不修改像素。完好/破损共用位置和尺寸。

只验证一个体型及“亚麻—绗缝—链甲”配套组合。链甲破口和边缘绘有对应绗缝衬色，尚不代表任意材质、任意两甲或所有体型自由互套。

## 动作规则

身体和衣甲静止，武器独立移动；受击对象作为完整棋子短促后退。剑短挥、枪前刺、弓微动与独立箭矢离弦。路径连续并回到同一待机姿态；命中短停顿，落空不制造目标伤损。U47保留U46时长与事件节奏，仅校准放大武器后的空间位置。弓全程在脸外侧，箭矢起点随之调整。

表现时钟不决定伤害、命中、扣损、死亡或存档。评审靶的甲损为固定演示，不写入战役。声音沿用三段合成示意，仅检验节奏，未作为正式音效；命中效果沿用生成原画。

前后对照读取冻结的 `catalog-v1.json` 和旧待机位置，以同一镜头倍率绘制；不得分别把两版放大至同一占格大小掩盖比例差异。

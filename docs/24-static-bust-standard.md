# H 静态半身：固定盘面与武器反馈标准

2026-09-20，U48修订。主AI独立制作与验证，无子智能体。

补充研究：[模组社区的资产制作经验](research/modding-art-workflow-findings.md)。共同坐标校准、跨装备试穿和1×修整列为下一轮建议；本次研究未改变下方已实现规格或自动启动新工具开发。

## 定标顺序

用户明确要求：**固定底座 → 依据底座设计身体和衣甲 → 确定头部大小及落位 → 最后统一截取。** 这取代U47“让短袖和上臂伸出底座”的理解，也取代明显外露颈段。静态身体、无手、头身分离、H画风继续有效；Spine／三维降二维仍仅作未来候选。

当前单体型样板固定使用H底座原画，宽64逻辑像素，底部中心(0,0)。身体和所有衣甲围绕同一盘面设计，完好/甲损不能改变底座规格。该数值是本轮验证规格，不是用户批准的全库最终数值。

完整衣甲保留长袖、下摆与材质结构；棋子只显示与盘面匹配的胸肩部分。近远肩形成略高于底座后半部的侧向弧形，显示区基本覆盖盘面，外围留边框。不得保留明显袖口、外露短上臂，也不得为了收口把衣服在腋下收紧。

头部沿用同一H面容/脸伤，宽34，锚点(3,-28)；下颌贴近领口，后脑与衣领形成遮挡，不展示整段脖子。身体底层为素色内衣外观，本轮没有新裸胸解剖资产。

## 装配与资产

层序：底座 → 内衣身体 → 亚麻 → 绗缝 → 链甲 → 独立头 → 盾/武器/箭。

底座图集矩形643×260，等比显示宽64、高约25.88。依据底座原画内盘边缘定标：原图矩形内椭圆中心(321,87)、半径(289,72)，换算后 `bust_crop` 中心约(-0.0498,-17.2193)、半径约(28.7652,7.1664)。下缘采用这个盘面的前半圆弧，紧贴金属边框内侧，不能使用独立的平切线或任意圆角。主体保留原画肩胸轮廓；头、武器和底座不受衣甲窗口截取。

衣甲完整画布显示宽71–72.5，顶部锚点(3.5,-42)，底部大幅超出盘面；显示部分受共同边界限制，不能把完整画布宽度当成最终棋子宽度。按用户追加反馈，头、身体及所有衣甲作为一组向右微移2逻辑像素；底座与盘面截取边界固定，右侧微露底座边缘。所有部件等比缩放，完整PNG不被程序涂改。窗口仅裁取可见区域，不生成假袖口、假伤痕或领肩盖缝。

原画领口内衬阴影保留。当前只验证一个体型及“亚麻—绗缝—链甲”配套组合，破口衬色已画入对应甲，不推定任意颜色/甲种/领型通用。完整源图及截取过程见[最新评审页](../art/validation/2026-09-20-static-bust-v3/index.html)“盘面与截取”。金色线只用于该页的检查示意，不属于成品人物。

## 武器动作

| 类型 | 待机与出手 | 回收与结果 |
| --- | --- | --- |
| 剑盾 | 保留短挥斩，盾位置按新头领关系校准 | 命中短停顿，落空缩短停顿 |
| 长矛 | 接近水平、略向上，短收后沿枪轴前刺 | 平稳回到同一平持姿态 |
| 弓 | 胸前低位下垂；先向迎敌侧移出再抬起瞄准 | 离弦后反向收回，全程不穿地，避免抬收扫脸 |
| 箭 | 从预备箭尖的同一位置/方向进入固定抛物线 | 箭尖沿切线转向；命中跟随完整目标反馈，落空在靶前落地 |

弓循环1.48秒，44%离弦、76%到达结果点；剑0.86秒、枪0.82秒。预览纯函数支持暂停/拖动/变速，事件跨帧只触发一次。

全部为表现样板，弹道不计算真实碰撞或决定命中、伤害、资源与伤亡。示意目标甲损不写战役存档；声音沿用合成节奏示意，命中效果沿用生成原画。倒下可能重伤幸存的规则方向不变。

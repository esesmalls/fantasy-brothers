# H 静态半身：穿戴与武器反馈样板

2026-09-20，U46。主AI独立制作、集成和审阅，未启动子智能体。

## 已采用的方向

用户明确选择回归 Battle Brothers 式静态半身：取消站立手部和拼装手臂，人物向右侧转，胸线下收口，配低底座，衣甲沿用同一构图与尺度。H仍是画风基准。Spine／三维降二维仅留作未来候选，本轮没有安装或迁移。

该决定替代19标准中“完整双手、高位握点、肩肘腕链”的旧要求。A批次保留为退回记录，不继续扩量；武器独立移动，人体不做局部骨骼或三姿硬切。

## 本轮可直接评审的内容

- 一名H风格佣兵：独立无颈头部、提供颈根的裸肩胸身体、亚麻内衬、低铁底座。
- 绗缝甲、外层链甲；两甲均有完好和破损原画。脸部受伤独立切换，不与甲损绑定。
- 剑盾、长枪、短弓；独立剑、枪、弓、盾、箭、绘制的金属命中效果。
- 三套武器运动，以及命中、格挡、落空结果。目标的反馈作用于整个棋子，头身衣甲与底座不互相转动。
- [离线评审页](../art/validation/2026-09-20-static-bust/index.html)、根目录 `Review-Static-Bust.cmd`、Windows独立导出。

正常战役仍为0.1.5.1，本样板通过独立入口运行。没有把尚待用户评审的新人像批量替换全部单位，也没有顺带推进招聘后勤等四步内容。

## 构图与分层约束

地面中心为固定原点。头宽51逻辑像素，衣甲宽76–79，底座宽75；每个部件均按统一比例缩放，不横向压扁。站立不展示腰腹、腰带或胳膊；身体在胸线下的浅弧处与底座内沿接触。所有武器共用这套身体尺度，不为长枪缩小人物。

实际层序为：底座 → 裸身体 → 亚麻 → 绗缝 → 链甲 → 独立头 → 副手盾 → 主武器／箭。头的下缘沿真实胡须与下颌，不保留跨过喉咙的黑色截线。颈根属于身体，填满领口；脸位于高侧领之前，避免领口压进嘴或胡须。

所有衣甲使用完整、有设计的透明图层；没有将领口、肩膀、腰带截成小矩形覆盖接缝，没有旧A手臂、肩袖补丁或动态握点。图集索引只读PNG并记录矩形和锚点，不生成或修改任何原画像素。

**已验证的是一个体型及“亚麻—绗缝—链甲”组合。** 链甲原画中有配套绗缝衬边及破口内衬，当前不声称支持任意颜色内衬、任意两甲互套或所有体型。扩展时须继续按母版生产，不靠自动拉伸适配。

## 动作规则

| 类型 | 预备和出手 | 结果与回收 |
| --- | --- | --- |
| 剑盾 | 剑在面容外侧短抬，绕自身转轴短挥；盾留在迎敌侧 | 命中固定短停顿，再回弹、回位；落空缩短停顿 |
| 长枪 | 枪尾保持在棋子附近，转向目标并沿枪轴前刺 | 枪尖接触目标外缘；回收后回到同一待机位置 |
| 弓 | 弓轻微蓄势和回弹，独立箭矢离弦 | 箭的释放先于目标命中；落空不制造目标伤损 |

不表现拉弦手、不伪装完整人体动作。武器路径连续插值，回到原待机姿态。只读表现时钟触发声音／效果，不能决定伤害、命中、装备扣损、死亡或存档。评审靶的甲损是固定演示结果，不写入真实战役。

本轮复用旧评审器的三段合成示意音效，仅检验发声节奏；不是正式声音资产。绘制命中效果来自本轮imagegen，不用几条程序直线充当成品效果。

## 制作中发现并解决的问题

1. 首张衣甲图集部件挤到边缘：重新生成留白版本，未裁去肩尖。
2. 空领口直接套独立长颈头，出现背景穿孔和高领遮胡须：补做真实肩胸身体，头改成沿下颌分离，调整层序。
3. 短颈头仍有喉部截线：通过图像工具去掉头图的全部颈皮，由身体承托下颌；不是程序涂抹。
4. 长枪与弓待机下缘过低、1×检查区可能裁枪：校准整件武器的位置和评审留白。

过程图原样保留在sources，当前运行资源对应manifest中的选用文件；不可误将过程稿当成生产资源。

## 验证与放行边界

专项123项通过：等比缩放、状态切换位置、三武器路径起止和连续性、不同速度／跳过时一次性事件、暂停和拖动。主入口UI流程301项通过。最终Windows导出运行生成110张真实截图，包括每武器32帧、三种背景、甲损、分层、裸身与结果对照。

读像素比较确认三组动作中避开武器的脸区、底座区均保持一致；这证明局部不再漂移，不是审美通过的替代。主AI另直接查看合成、浅底、伤损、分层与接触帧。浏览器离线页面24项检查通过，桌面1440与窄屏560无水平溢出。

范围尚不包括多人物体型、多朝向、更多甲种、独立盔帽／发须、这套新构图的倒伏／死亡或正式音效；正常战斗接入待本轮样板评审。倒地可能重伤幸存的语义继续有效，未更改游戏规则。最终美术质量由用户评审，不以生成数量或技术测试数宣称正式放行。

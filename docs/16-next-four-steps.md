# 下一批四步：招聘、契约、部署与人物后果

更新：2026-09-19。本批承接0.1.5人物成长，目标是让“招谁、接什么、谁上场、如何承受损失”成为一个可玩的经营闭环。四步可以作为一次开发批次交付，但必须按下列顺序逐步通过规则、存档和实际导出验证；前一步未稳定时，不并行叠加后一步的永久状态。

最新整合：用户已确认美术制作方式并要求详细计划；实施将先验证共享美术样板、补齐当前框架资产，再依次接入本文件四步。具体资产、UI、接口与整批验收见 [18美术生产计划](18-art-production-plan.md)。当前四步尚未实现，本轮仅交付计划。

## 已知基础与设计边界

- 已实现事实：四个出战位、人物属性与训练、装备库存、固定路线、单一粮仓契约、返营休养/短工/补员、永久死亡和旧档迁移。
- 用户已确认：高出身以更高招聘价和持续维护费平衡早期优势；普通人都能培养；伤残与性格变化要产生可选择的后果；倒下不一定死亡，战斗胜利后可能幸存并受重伤。
- 本文原创提案：以下候选池规模、契约样板、部署流程、伤势和事件均待实现与试玩，不代表已批准数值。
- 本批不加入自由探索、繁衍、完整士气、全身部位伤害、义肢或大量随机职业。

## 第一步：招聘与后勤经济

最小内容：一个保存的招聘候选池，至少同时展示“昂贵且即刻可用的成熟出身”和“便宜但要投入训练的普通出身”；签约前并列显示一次招聘费、持续维护费、装备归属、已会本领和培养缺口。维护费按公开周期结算，预告下一次扣款，不在读档或重复开界面时多扣。

真实闭环：返营查看候选 → 比较即时战力与长期成本 → 招募或保留空位 → 配装/训练 → 出征 → 经过维护结算后再次判断是否留人。普通人必须在现有训练规则下能达到至少两种合格职责；高出身节省的是前期时间与风险，不提高通用能力上限。

经济软锁保底：钱粮不足时保留一项低风险短工和一项带明确债务/低配装备的紧急补员通路。保底消耗时间、推迟高收益契约，且不发高级经验、稀有装备或可反复套利的配发品。候选池生成即保存；刷新需要公开成本和期限，不能靠重开菜单或读档重抽。

待试玩值：候选数量、招聘费、维护周期与费率、刷新节奏、债务上限、普通人成材所需的任务/训练时间。先比较“成熟者若干次远征的总成本”和“普通人训练及占位成本”，不先写死工资表。

验收：连续招退不能赚钱；扣费只发生一次；全员阵亡、零金和零粮仍有合法恢复路线；候选死亡或被招募后ID不复用；普通人与高出身使用同一学习资格检查。

## 第二步：真正不同的契约

最小内容：保留粮仓守卫，并增加一个低风险恢复型样板和一个战术目标不同的样板。契约差异必须同时落在目标、准备成本、战场选择或失败后果中的至少两项，不能只改报酬文字。优先复用现有地图、敌人、物件和元素规则，减少新资产。

建议样板：恢复型工作允许带伤队伍用时间换基础钱粮，但成长与战利品有限；战术型工作在“保护物件/及时撤出目标”之间形成取舍，并让出发前携带物资影响可用方案。每份报价显示危险、期限、预计消耗、雇主底线和撤退后果。

真实闭环：地点查看报价 → 依据名册状态选约 → 选择路线和准备 → 完成不同目标或撤退 → 一次性清点钱粮、声望、伤亡与世界后果 → 返回新的报价池。契约定义ID与本次实例ID分开；实例生成后保存，胜败和奖励使用唯一claim。

待试玩值：低风险收益、期限、敌人强度、保护目标耐久、预付与尾款比例。恢复型工作必须能止住败局，又不能成为无限等待和练级的最优解。

验收：两类契约要求不同决策；胜利、目标损失、撤退和团灭均可结算；低资金时至少有一个合法候选；无合法候选时使用保存的平静/短工回退；读档不换约、不重复领奖。

## 第三步：出战、替补与部署

最小内容：名册允许拥有多于四名存活人类，契约出发前选择最多四名出战者并安排有限起始位置，其余留作替补。界面同时显示伤势、装备、契约目标和未出战代价；开始行军后锁定本次名单，战后经验只给实际有效参战者。

真实闭环：招聘形成候补 → 根据契约挑选四人 → 在公开区域调整前后位 → 确认后生成并保存部署 → 战斗伤亡迫使下一次轮换 → 伤员休养、替补上阵；导师功能留作后续扩展。替补不是额外行动次数，也不能在结算前换入领奖。

规则接口需求（由主代理交战斗工程确认）：新战斗只读取已保存的`deployment_instance_id`、队员ID与起始格；预览和开战共用合法格检查；进行中的旧战斗继续使用原快照，不按新名册重排。

待试玩值：名册上限、后备位数量、部署区域大小、留营维护差异、导师占用。首版只验证“伤员休息还是冒险上阵”和“成熟者带新人”两种选择，不做复杂编队加成。

验收：重复确认不复制人或装备；死亡、伤员、战犬主人缺席和不足四人都有合法名单；非法格不能开战；保存加载保持名单与站位；未出战者不获战斗经验，营地训练按既有规则单独结算。

## 第四步：倒地伤亡、伤势、永久伤残与性格最小样本

按最新用户澄清，先接通“战中倒地失能 → 胜利后清点 → 重伤幸存或确认死亡”。HP归零者退出行动、AI目标和有效作战人数，本场不再起身；倒地阶段不丢装备、不写纪念册，不提前显示必死尸体。战后先确定伤亡，再处理重伤/装备/经验、纪念或性格事件，最后发放合同与成长结算；同一人物同一战斗只解析一次。

新战斗保存独立伤亡随机依据，首次倒地时记录人物ID、来源行动及唯一伤亡ID；战果结束时解析并一次保存，重开结果页或读档不能重抽。人类与战犬都需明确重伤/死亡结果，犬不套人类性格或训练点。无持久名册的敌人首先只作本战失能，不扩俘虏系统。

重伤幸存者保留人物与装备实例及真实耐久，HP写为合法存活值并承担公开休养成本；确认死亡后才执行现有阵亡损失。经验沿用有效参战资格，倒地本身不发奖励。是否永久伤残以有来源的结果决定，重伤不等于必然残疾。候选参数包括幸存率、休养禁战时间、后续可冒险出战条件与永久伤残关联。

战败/撤退边界尚是提案：本批优先仅在胜利控制战场时给倒地者幸存机会；败退未撤出的失能者按失败伤亡处理，出征/撤退决定处明示。具体规则实现前应统一胜/败/撤退三分支；不将此提案说成用户已确认细则。旧已确认死亡者不复活，旧进行中战斗继续原规则；新机制提升战斗规则版本，只从新战斗启用。

最小内容：一种会按天恢复的暂时伤势、一种永久伤残、一个有代价也有应对的性格转折。建议暂时伤势为腿部拉伤，限制连续位移；恶化样板为膝部旧伤，长期提高追击/长距离移动成本，但可通过短步站位、盾护或后勤职责继续发挥。伤残不免费赠送强力专长，自伤和友伤不产生培养收益。

新增战后“重伤幸存”先用一般重伤与休养状态承接，不凭总HP伪造腿部命中；腿伤/膝伤样本须有明确来源。重伤阶段的禁战结束后，仍可能有可恢复伤势，是否冒险上阵按公开规则决定。

性格样板“谨慎救援者”来自真实救援或撤退经历：人物更愿意准备退路并开放相关事件选项，同时在仓促追击类选择上承担公开成本。其具体战术效果需要主代理批准统一状态/触发接口后再定，不由内容数据直接改战斗核心。

可接入事件卡：`evt_camp_rescue_reckoning_v1`。触发：返营、事件未发生、记录中有一次合法救援/带伤撤出且相关人物存活；角色缺席则延后一次，死亡则改为无奖励的纪念路径。选项A“共同复盘”消耗营地时间，立即推进伤势恢复，延迟形成“谨慎救援者”候选；选项B“让他自行静养”不占导师，恢复较慢且不会产生性格候选；选项C“仍要他下次出阵”仅在玩家主动选中伤员时出现，预告恶化风险并保存结果。每名角色最多触发一次，同一根战斗记录不能重复触发。

语义澄清：0.1.5.1仍是HP归零即死亡；本批按最新要求加入胜利后的倒地重伤幸存，但不加入战斗中救起/复活。事件可读新结算中真实幸存/带伤撤出，若采用“救援者”关系须有独立保护经历来源，不由美术或文案捏造人物关系或导师功能。

角色路径：救援者死亡时由被救者/团体记忆承接简短后果；被救者死亡时事件改为失败复盘；两者都缺席时只记履历并关闭实例。主线和契约池不依赖任一永久可死亡角色。

验收路径：使用真实带伤撤出/重伤幸存来源返营，关系类选项另要求真实保护来源 → 分别选择合法选项 → 推进天数/再次出战 → 检查即时与延迟后果。固定伤亡随机值分别覆盖胜利后幸存和死亡，测试多名倒地、犬、最后有效队员倒地、敌方全部失能、败退及旧规则战斗；重复读档/结算/返营不重抽、不重复掉装、经验或事件。存活与死亡互斥，暂时伤势恢复不清除已有永久伤残；旧死者不复活，旧档无来源不补伤残或性格。

## 借鉴来源与原创边界

人物背景成本、伤势轮换的启发记录在[人物研究](research/character-development-findings.md)，条件事件和持久后果的研究记录在[肉鸽研究](research/roguelite-findings.md)。本文四步顺序、经济保底、三个契约样板、部署闭环和事件卡均为本项目原创组合；未导入参考游戏的文本、代码、数值或素材。

遗留问题：维护费按日还是按契约结算、低风险工作是否占用路线、伤员冒险上阵的恶化算法、性格的首个战术效果、名册上限与候选刷新频率，都需要完成前置接口后由实际试玩决定。

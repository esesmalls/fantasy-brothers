# 《灰烬誓约》0.1.2 试玩说明

这是承接上一台电脑工程的机制原型，不是商业美术或完整战役成品。用一张代表战场检验经营、选择、战斗、伤亡和成长之间的循环。

## 启动

Windows 64 位：双击同目录 `FantasyBrothers.exe`。项目工作区也可以双击根目录的 `Play.cmd`。

无需另装 Godot。没有联网或账号要求。本次实际验证设备使用 Windows 与 NVIDIA OpenGL；其他显卡及干净机器尚未覆盖。

## 推荐的第一轮

1. 建立「自由佣兵团」，种子输入 `1709`。查看四名队员，在营地中间选择「渡口旧道」出征；熟悉后再试「山脊险径」。两条路线会提前列出粮食、天数、敌情、报酬和补给。
2. 阅读路上事件，选择要兑现的承诺，再进入战场。
3. 每人有 6 行动点。先选底部动作，把鼠标放到棋盘看预览，再单击目标。移动每格 2 点；常规攻击 3 点。
4. 试一次盾击制造破绽、让长枪手接力；也可打破油罐后投火，或用水灭火制造蒸汽。
5. 结束当前队员回合后，下一人行动；轮到敌人会自动执行。空格结束回合，Esc 切回移动。
6. 尽量保护粮仓。战斗后点击「清点伤亡，返回营地」，选择成长，再休养、修补和补给。
7. 完成三次远征查看短篇结尾。此后可以继续经营；另一轮试「雾林猎团」，由猎人下令让战犬执行。

## 本轮重点复验

- 战场铺满视口，底部集中当前人物、招式、战具与行动顺序。轮到猎人时也能完整看到三种战犬指令。
- 将鼠标移到人物上身或底座，查看敌我、战犬的生命、护甲、行动、命中、射程、专长与状态来源/期限；敌人回合也能查看。底部行动顺序中的名字同样可悬停。
- 将鼠标移到油罐、木栅、粮仓、油火、水和蒸汽上，查看耐久、阻挡、破坏后果或区域期限。信息卡不会挡住操作栏。
- 左上角战报默认只显示最新一条，点击可展开并滚动查看完整战斗日志。
- 当前人物的箭头、姓名与双环、友军穿越而不重叠停留、攻击范围和波及预览继续保留。战场状态使用盾形、火焰等原创图示；危险短语仅取自实际状态，未增加士气数值。
- 普通窗口与小窗口各打一轮，重点观察悬浮信息是否容易找到、底部文字和按钮是否清楚、点击相邻空格是否准确。
- 元素效果、受击、正常/加速/跳过演出保留；两条远征路线继续可用。

## 需要看懂的代价

- 油火会伤到友军；火区直接伤生命，每名单位每轮最多受一次火区伤害。水火蒸汽会遮挡双方远程。
- 攻击先消耗护甲。盾击命中施加破绽，长枪尝试利用时即消耗，未命中也会消耗。
- 主动离开贴身敌人可能遭反击；推开属于强制位移，不触发脱离反击。
- 猎人指令花行动点，不刷新战犬行动点；战犬占一个出战位，会死亡。
- 死亡不会在回营后复活。补员接替岗位；无钱时可以预支签约款，之后从报酬中偿还。
- 无钱缺粮仍有短工与缓慢恢复通路。撤退也能结算，但没有契约报酬。

## 存档

事件、选择、行动、结算、成长后自动保存。顶部可独立手动保存与读取。战场状态、随机数状态、已生成事件与成长候选一同保存；重新打开菜单不会重新抽取。

Windows 存档位于 `%APPDATA%\FantasyBrothersPrototype\`：自动档 `campaign.json`，手动档 `manual.json`，各有上次完整快照 `.bak`。主档损坏时会尝试读取备份；不兼容或损坏文件不会被当作正常进度。`qa/` 是自动测试目录，不是玩家进度。

0.1 的有效旧档可继续：补齐旧道记录，保留已有资源、队伍、事件和随机状态，后续采用 0.1.1 的通行规则。0.1.2 沿用 0.1.1 战斗规则与存档结构。三台电脑的个人进度不会经 Git 自动同步；关闭游戏后可复制上述存档及备份到另一台同目录，注意保留较新的进度。

正常、加速、跳过只改变演出速度，不改变伤害、消耗与回合。

## 当前边界

- 2 类佣兵团、4 个出战位；盾枪、远程与一只战犬的代表机制。
- 6 个条件事件、5 类专长与空池回退，3 次远征产生短篇收束。
- 2 条有代价预告的远征路线，选择、结果与历史保存；不是自由探索地图。
- 1 张复用战场、3 类可破坏战术物件及粮仓目标；难度与补给受选择影响。
- 原创程序绘制半身棋子，含移动、攻击、受击与元素反馈；尚无音效、商业角色动画或正式美术。
- 尚无装备交易/换装、自由路线地图、完整三幕不同关卡、疲劳/士气/高低差、丰富施法者、遗物或更多兽种。
- 当前 AI 和经济数值属于验证假设。自动检查通过不代表趣味性和平衡已经通过真人验收。

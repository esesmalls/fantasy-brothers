# 《灰烬誓约》0.1.3 试玩说明

这是承接上一台电脑工程的机制原型，不是商业美术或完整战役成品。用一张代表战场检验经营、选择、战斗、伤亡和成长之间的循环。

## 启动

Windows 64 位：双击同目录 `FantasyBrothers.exe`。项目工作区也可以双击根目录的 `Play.cmd`。

无需另装 Godot。没有联网或账号要求。本次实际验证设备使用 Windows 与 NVIDIA OpenGL；其他显卡及干净机器尚未覆盖。

## 推荐的第一轮

1. 建立「自由佣兵团」，种子输入 `1709`。先在右侧进入「营地生活」，查看队员和整备操作，再返回边境地图。
2. 在地图右侧比较「渡口旧道」和「山脊险径」的粮食、天数、敌情、报酬与工具；点击路线按钮接约出发。第一轮建议旧道。
3. 点击「继续行军」，看旗帜逐站移动。途中事件出现后选择回应，再继续赶往雨夜粮仓。点击地图地点只是查看见闻，不会出发或扣费。
4. 抵达后查看契约准备并进入战场。每人6行动点；选底部招式/战具，悬停看范围和预览，单击执行。移动每格2点、通常攻击3点；空格结束回合。
5. 试一次盾击破绽接长枪攻击，或打破油罐再投火、用水灭火形成蒸汽。悬停敌我、战犬和物件可看详情。
6. 胜利、败北或撤退后「清点战果 · 离场」。如有成长先选择专长，再在地图点击「返回灰岸营地」。伤亡与消耗保留；返回后休养、修甲、补给或补员。
7. 回地图接下一份契约。第三次远征会经过裂钟桥头并收束短篇，此后仍可继续。另一轮试「雾林猎团」与山脊险径。

## 本轮重点复验

- 地图与生活：开局营地位置明确，浏览地点、切换地图/名册不扣资源；地图、事件、契约准备之间能随时查看已保存行程。
- 旅行：旗帜随「继续行军」移动；出发一次扣去程2/3粮与1天，逐站不重复扣。第三次会实际到桥头处理钟声事件。
- 存读：分别在刚出发、途中、事件待选、准备战斗和准备返营时保存读取，地点、选择和物资应保持一致，不重新抽事件。
- 返营：胜利、撤退和失败都能清点后返营。零金零粮或全员死亡也应能回营，使用短工、缓慢修养/修甲及预支补员继续经营。
- 战斗：原有底部HUD、悬浮信息、射程、友军穿行及元素受击反馈继续保留。普通窗口与小窗口各试一轮。

## 需要看懂的代价

- 油火会伤到友军；火区直接伤生命，每名单位每轮最多受一次火区伤害。水火蒸汽会遮挡双方远程。
- 攻击先消耗护甲。盾击命中施加破绽，长枪尝试利用时即消耗，未命中也会消耗。
- 主动离开贴身敌人可能遭反击；推开属于强制位移，不触发脱离反击。
- 猎人指令花行动点，不刷新战犬行动点；战犬占一个出战位，会死亡。
- 死亡不会在回营后复活。补员接替岗位；无钱时可以预支签约款，之后从报酬中偿还。
- 无钱缺粮仍有短工与缓慢恢复通路。撤退也能结算，但没有契约报酬。

## 存档

事件、选择、行动、结算、成长后自动保存。顶部可独立手动保存与读取。战场状态、随机数状态、已生成事件与成长候选一同保存；重新打开菜单不会重新抽取。

Windows 存档位于 `%APPDATA%\FantasyBrothersPrototype\`：自动档 `campaign.json`，手动档 `manual.json`，各有上次完整快照 `.bak`。主档损坏时会尝试读取备份；不兼容或损坏文件不会被当作正常进度。`qa/` 是自动测试目录，不是玩家进度。

0.1 的有效旧档可继续：补齐旧道记录，保留已有资源、队伍、事件和随机状态，后续采用 0.1.1 的通行规则。0.1.3 沿用 0.1.1 战斗规则，并新增版本化世界状态。有效旧档加载后接入地图；正在进行的事件、战斗与成长保留原阶段，不重新扣去程代价或抽选。三台电脑的个人进度不会经 Git 自动同步；关闭游戏后可复制上述存档及备份到另一台同目录，注意保留较新的进度。

正常、加速、跳过只改变演出速度，不改变伤害、消耗与回合。

## 当前边界

- 2 类佣兵团、4 个出战位；盾枪、远程与一只战犬的代表机制。
- 6 个条件事件、5 类专长与空池回退，3 次远征产生短篇收束。
- 6 处固定地点、2 条聚合行程、1 份可重复粮仓契约；地点发现、逐站旅行、事件、战斗、返营生活和存读接通。尚非自由点击任意地点行军或随机开放世界。
- 1 张复用战场、3 类可破坏战术物件及粮仓目标；难度与补给受选择影响。
- 原创程序绘制半身棋子，含移动、攻击、受击与元素反馈；尚无音效、商业角色动画或正式美术。
- 尚无装备交易/换装、自由选边行军、完整三幕不同关卡、疲劳/士气/高低差、丰富施法者、遗物或更多兽种。
- 当前 AI 和经济数值属于验证假设。自动检查通过不代表趣味性和平衡已经通过真人验收。
